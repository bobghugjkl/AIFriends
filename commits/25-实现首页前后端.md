## 一、这次提交做了什么

把首页（HomepageIndex）从一行"首页"文字变成了**全平台角色浏览页**——展示所有用户创建的角色卡片，同样支持无限滚动。后端新增首页 API，不需要登录就能访问（和 get_list 不同，首页展示所有用户的角色，不限制某个用户）。

## 二、使用了什么技术

| 技术/工具 | 用途 |
|-----------|------|
| Django `Character.objects.all()` | 查询全平台所有角色，不限定用户 |
| Tailwind `grid-cols-[repeat(auto-fill,minmax(240px,1fr))]` | 自动响应式网格布局，无需媒体查询 |
| 无限滚动模式 | 复用 SpaceIndex 的 IntersectionObserver 机制 |

## 三、完整源代码

### 3.1 `homepage/index.py`——后端首页 API

**文件**：`backend/web/views/homepage/index.py`（新文件，完整内容）

```python
from rest_framework.views import APIView
from rest_framework.response import Response

from web.models.character import Character


class HomepageIndexView(APIView):
    def get(self, request):
        try:
            items_count = int(request.query_params.get('items_count'))
            characters_raw = Character.objects.all().order_by('-id')[items_count: items_count + 1]
            characters = []
            for character in characters_raw:
                author = character.author
                characters.append({
                    'id': character.id,
                    'name': character.name,
                    'profile': character.profile,
                    'photo': character.photo.url,
                    'background_image': character.background_image.url,
                    'author': {
                        'user_id': author.user_id,
                        'username': author.user.username,
                        'photo': author.photo.url,
                    }
                })
            return Response({
                'result': 'success',
                'characters': characters
            })
        except:
            return Response({
                'result': '系统异常，请稍后重试'
            })
```

**和 `get_list` 的关键区别**：

| | `get_list` | `homepage/index` |
|---|---|---|
| 查询范围 | `Character.objects.filter(author=user_profile)` | `Character.objects.all()` |
| 需要登录 | 不需要 | 不需要 |
| 需要参数 | `user_id` + `items_count` | 只需要 `items_count` |
| 返回用户信息 | 返回 `user_profile` | 不返回 |

首页查全部用户的角色；个人空间只查某个用户的。

**同样有分页 bug**：`items_count + 1` —— 又是调试用的 1 条限制，后续会修。

### 3.3 `HomepageIndex.vue`——首页前端

**文件**：`frontend/src/views/homepage/HomepageIndex.vue`（完整内容）

```vue
<script setup>
import {nextTick, onBeforeUnmount, onMounted, ref, useTemplateRef} from "vue";
import api from "@/js/http/api.js";
import Character from "@/components/character/Character.vue";

const characters = ref([])
const isLoading = ref(false)
const hasCharacters = ref(true)
const sentinelRef = useTemplateRef('sentinel-ref')

function checkSentinelVisible() {  // 判断哨兵是否能被看到
  if (!sentinelRef.value) return false

  const rect = sentinelRef.value.getBoundingClientRect()
  return rect.top < window.innerHeight && rect.bottom > 0
}

async function loadMore() {
  if (isLoading.value || !hasCharacters.value) return
  isLoading.value = true

  let newCharacters = []
  try {
    const res = await api.get('/api/homepage/index/', {
      params: {
        items_count: characters.value.length,
      }
    })
    const data = res.data
    if (data.result === 'success') {
      newCharacters = data.characters
    }
  } catch (err) {
  } finally {
    isLoading.value = false
    if (newCharacters.length === 0) {
      hasCharacters.value = false
    } else {
      characters.value.push(...newCharacters)
      await nextTick()

      if (checkSentinelVisible()) {
        await loadMore()
      }
    }
  }
}

let observer = null
onMounted(async () => {
  await loadMore()

  observer = new IntersectionObserver(
    entries => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          loadMore()
        }
      })
    },
    {root: null, rootMargin: '2px', threshold: 0}
  )

  observer.observe(sentinelRef.value)
})

onBeforeUnmount(() => {
  observer?.disconnect()
})
</script>

<template>
  <div class="flex flex-col items-center mb-12">
    <div class="grid grid-cols-[repeat(auto-fill,minmax(240px,1fr))] gap-9 mt-12 justify-items-center w-full px-9">
      <Character
        v-for="character in characters"
        :key="character.id"
        :character="character"
      />
    </div>

    <div ref="sentinel-ref" class="h-2 mt-8"></div>
    <div v-if="isLoading" class="text-gray-500 mt-4">加载中...</div>
    <div v-else-if="!hasCharacters" class="text-gray-500 mt-4">没有更多角色了</div>
  </div>
</template>

<style scoped>

</style>
```

和 `SpaceIndex` 的无限滚动逻辑完全一样，唯一的区别：
- 调用 API 是 `/api/homepage/index/`
- 角色卡片**没有传 `canEdit`**（默认 undefined/falsy），用户看不到编辑按钮
- 没有 `UserInfoField`（首页不需要显示别人的用户信息）

## 四、CSS 网格布局

```html
<div class="grid grid-cols-[repeat(auto-fill,minmax(240px,1fr))] gap-9 ...">
```

这是 Tailwind 的**任意值**语法 `[...]`。`grid-cols-[...]` = `grid-template-columns: ...`。

- `repeat(auto-fill, ...)` —— 自动填充列，一行塞多少列取决于容器宽度
- `minmax(240px, 1fr)` —— 每列最小 240px，最大平分剩余空间

**效果**：容器宽度变化时，自动调整每行列数——宽屏显示 5-6 列角色卡片，窄屏可能只有 2-3 列。不需要写媒体查询断点。
