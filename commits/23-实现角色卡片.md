## 二、`Character.vue`——角色卡片组件

```javascript
const props = defineProps(['character', 'canEdit'])
const emit = defineEmits(['remove'])
const isHover = ref(false)
```

- `props.character` —— 角色数据对象（id、name、photo、background_image、profile、author）
- `props.canEdit` —— 布尔值，控制是否显示编辑/删除按钮。在个人主页（自己的空间）传 true，首页传 false（只能看别人的）
- `emit = defineEmits(['remove'])` —— 声明"我会向父组件发出 `remove` 事件"

**删除角色**：
```javascript
async function handleRemoveCharacter() {
  const res = await api.post('/api/create/character/remove/', {
    character_id: props.character.id,
  })
  if (res.data.result === 'success') {
    emit('remove', props.character.id)  // 通知父组件从列表中移除
  }
}
```

删除成功后通过 `emit('remove', id)` 通知父组件。父组件 `SpaceIndex` 处理：
```javascript
function removeCharacter(characterId) {
  characters.value = characters.value.filter(c => c.id !== characterId)
}
```

**卡片HTML结构**：

```html
<div class="avatar cursor-pointer" @mouseover="isHover=true" @mouseout="isHover=false">
  <div class="w-60 h-100 rounded-2xl relative">
    <!-- 背景图 + 悬停放大效果 -->
    <img :src="character.background_image" :class="{'scale-120': isHover}" alt="">
    
    <!-- 底部渐变遮罩 -->
    <div class="absolute left-0 top-50 w-60 h-50 bg-linear-to-t from-black/40 to-transparent"></div>

    <!-- 编辑/删除按钮（只有自己的角色才显示） -->
    <div v-if="canEdit && character.author.user_id === user.id">
      <RouterLink :to="{name: 'update-character', params: {character_id: character.id}}">
        <UpdateIcon />
      </RouterLink>
      <button @click="handleRemoveCharacter">
        <RemoveIcon />
      </button>
    </div>

    <!-- 头像（悬在背景图和渐变之间的圆形图片） -->
    <div class="absolute left-4 top-54 avatar">
      <div class="w-16 rounded-full ring-3 ring-white">
        <img :src="character.photo" alt="">
      </div>
    </div>

    <!-- 名字 + 简介覆盖在背景图底部 -->
    <div class="absolute left-24 right-4 top-58 text-white">{{ character.name }}</div>

**卡片视觉效果**（从上到下）：

|                        |
|  +---+ 角色名           |  ← 头像悬在渐变线上
|  |头像|                |

|                        |
+------------------------+
  作者头像  作者名          ← 卡片下方独立区域，点击进入作者空间
```

**`scale-120` + `transition-transform duration-300`**：Tailwind 的动画效果。鼠标移上卡片时背景图放大 1.2 倍（`scale-120`），过渡动画 300ms。

**条件渲染** `v-if="canEdit && character.author.user_id === user.id"`：两个条件同时满足才显示编辑按钮——允许编辑 且 当前用户就是角色的作者。
