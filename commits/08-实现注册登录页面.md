## 一、这次提交做了什么

给登录页和注册页填充了表单 UI——用户名输入框、密码输入框、提交按钮、互相跳转的链接。

## 二、使用了什么技术

| 技术 | 用途 |
|------|------|
| DaisyUI 表单组件 | `fieldset` 表单容器、`input` 输入框样式、`label` 标签、`btn-neutral` 中性色按钮 |
| Tailwind CSS | `flex justify-center` 弹性居中、`mt-30` 上边距、`w-xs` 固定宽度等原子化样式 |
| `RouterLink` | Vue Router 导航组件，链接到命名路由实现登录页与注册页互相跳转 |
| HTML 表单类型 | `type="password"` 密码输入遮挡、`placeholder` 占位提示文本 |

## 三、整体架构 / 数据流

### 表单 UI 结构（以登录页为例）

```
<div class="flex justify-center mt-30">              ← 外层居中容器
  └── <fieldset class="fieldset ...">                 ← DaisyUI 表单容器
       ├── <label>用户名</label>                      ← 字段标签
       ├── <input type="text" placeholder="用户名" />  ← 用户名输入框（纯 UI，尚无数据绑定）
       ├── <label>密码</label>
       ├── <input type="password" placeholder="密码" />← 密码输入框（纯 UI，尚无数据绑定）
       ├── <button class="btn btn-neutral">登录</button>← 提交按钮（纯 UI，尚无事件处理）
       └── <RouterLink :to="{name: '...'}">注册</RouterLink> ← 跳转到注册页
</div>
```

### 页面跳转关系

```
登录页 ←──── RouterLink ────→ 注册页
  │                              │
  │ "没有账号？前往注册"         │ "已有账号？前往登录"
  └──────────────────────────────┘
```

用户输入 ──→ 表单 UI（展示） ──→ (尚未实现) ──→ POST API

下一步将添加 `v-model` 数据绑定和 `@click`/`@submit` 事件处理。（什么是"数据绑定"？简单说就是把输入框和JavaScript变量"绑"在一起——你在输入框里打字，变量自动更新；变量变了，输入框里显示的文字也跟着变。`v-model`就是Vue里实现这种双向绑定的指令。什么是"事件处理"？`@click="handleLogin"`的意思是"当这个按钮被点击时，调用名叫`handleLogin`的函数"，`@`是Vue里`v-on:`的简写，用来监听浏览器事件）

## 四、代码改动

### 2.1 `LoginIndex.vue`——登录页

**改之前**（只有一行占位文字）：
```html
登录
```

**改之后**：
```vue
<template>
  <div class="flex justify-center mt-30">
    <fieldset class="fieldset bg-base-200 border-base-300 rounded-box w-xs border p-4">
      <label class="label">用户名</label>
      <input type="text" class="input" placeholder="用户名" />

      <label class="label">密码</label>
      <input type="password" class="input" placeholder="密码" />

      <button class="btn btn-neutral mt-4">登录</button>
      <div class="flex justify-end">
        <RouterLink :to="{name: 'user-account-register-index'}" class="btn btn-sm btn-ghost text-gray-500">
          注册
        </RouterLink>
      </div>
    </fieldset>
  </div>
</template>
```

**逐行讲解：**

- `<div class="flex justify-center mt-30">` —— 外层容器：
  - `flex` = 弹性盒布局
  - `justify-center` = 水平居中（弹性盒主轴为横轴）
  - `mt-30` = `margin-top: 7.5rem`（Tailwind 的间距比例：1 单位 = 0.25rem。30 × 0.25 = 7.5rem = 120px），把表单往下推，不贴屏幕顶部

- `<fieldset class="fieldset bg-base-200 border-base-300 rounded-box w-xs border p-4">` —— 表单容器：
  - `fieldset` —— DaisyUI 组件 class，专为表单设计的容器样式
  - `bg-base-200` —— DaisyUI 的次底色（浅灰）
  - `border-base-300` —— 边框用 DaisyUI 的第三级色
  - `rounded-box` —— DaisyUI 的圆角样式
  - `w-xs` —— `width: 20rem`（320px），Tailwind 固定宽度
  - `border p-4` —— 加边框 + 内边距 1rem

- `<label class="label">用户名</label>` —— DaisyUI 的 label 组件
- `<input type="text" class="input" placeholder="用户名" />` —— `type="text"` 是普通文本输入；`input` class 是 DaisyUI 的输入框样式；`placeholder` 是输入框为空时显示的灰色提示文字
- `<input type="password" class="input" placeholder="密码" />` —— `type="password"` 让输入的字符显示为 `••••`，防止被旁人窥视密码
- `<button class="btn btn-neutral mt-4">登录</button>` —— `btn-neutral` 是 DaisyUI 的中性色按钮（灰色调）
- `<RouterLink :to="{name: 'user-account-register-index'}">` —— 跳转到注册页。登录和注册页面通过底部链接互相连通

### 2.2 `RegisterIndex.vue`——注册页

**改之前**（只有一行占位文字）：
```html
注册
```

**改之后**：
```vue
<template>
  <div class="flex justify-center mt-30">
    <fieldset class="fieldset bg-base-200 border-base-300 rounded-box w-xs border p-4">
      <label class="label">用户名</label>
      <input type="text" class="input" placeholder="用户名" />

      <label class="label">密码</label>
      <input type="password" class="input" placeholder="密码" />

      <label class="label">确认密码</label>
      <input type="password" class="input" placeholder="确认密码" />

      <button class="btn btn-neutral mt-4">注册</button>
      <div class="flex justify-end">
        <RouterLink :to="{name: 'user-account-login-index'}" class="btn btn-sm btn-ghost text-gray-500">
          登录
        </RouterLink>
      </div>
    </fieldset>
  </div>
</template>
```

**与登录页对比**：
- **多了一个确认密码输入框**（`<input type="password" placeholder="确认密码" />`），防止用户输错密码
- **按钮文字**是"注册"而不是"登录"
- **底部链接**跳转到登录页而不是注册页

## 五、两个页面的关系

```
登录页 ←──RouterLink──→ 注册页
   │                       │
   │ "没有账号？注册"      │ "已有账号？登录"
   └───────────────────────┘
```

用户进入登录页 → 发现没注册 → 点底部"注册"链接 → 进入注册页 → 注册成功 → 点"登录"链接回登录页 → 用刚注册的信息登录。
