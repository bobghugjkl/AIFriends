## 一、这次提交做了什么

在聊天输入框旁加了**语音输入**功能——用户点击麦克风图标，浏览器实时录音，自动检测说话结束，把音频发给后端做语音识别，返回文字后自动发起聊天。

---

## 二、核心技术：VAD（语音活动检测）

引入 `@ricky0123/vad-web`——一个纯浏览器端的 VAD 库。VAD 的作用是在**不依赖服务端**的情况下判断"有没有人在说话"。

- `positiveSpeechThreshold: 0.8` —— 置信度 > 0.8 判定为"开始说话"
- `negativeSpeechThreshold: 0.65` —— 置信度 < 0.65 判定为"说话结束"
- `minSpeechFrames: 5` —— 至少连续 5 帧才能触发语音开始（防止短暂噪声误触发）
- `redemptionFrames: 5` —— 停顿 5 帧才判定说话结束（防止句中短暂停顿误结束）

**`onSpeechStart`**：开始说话时切换到动画条界面（32 根跳动的蓝色竖条）

**`onSpeechEnd(audio)`**：说话结束时拿到 `Float32Array` 格式的 PCM 音频数据 → 转为 PCM 16-bit（`Int16Array`）→ 发到后端 ASR 接口

## 三、`Microphone.vue`——语音输入组件

```javascript
const float32ToInt16 = (float32Array) => {
  const buffer = new Int16Array(float32Array.length);
  for (let i = 0; i < float32Array.length; i++) {
    let s = Math.max(-1, Math.min(1, float32Array[i]));
    buffer[i] = s < 0 ? s * 0x8000 : s * 0x7fff;
  }
  return buffer.buffer;
};
```

Float32 范围 [-1, 1] → Int16 范围 [-32768, 32767]。乘以 0x8000（32768）做线性映射。

## 四、`InputField.vue`——模式切换

```html
<form v-if="!showMic">   <!-- 文本模式 -->
  <input v-model="message">
  <MicIcon @click="showMic = true" />
</form>

<Microphone v-else />     <!-- 语音模式 -->
```

`showMic` 控制文本/语音模式的切换。`processId`（自增计数器）用于**取消正在进行的流**——用户说新话时旧流自动作废。
