## 一、这次提交做了什么

在聊天输入框旁加了**语音输入**功能——用户点击麦克风图标，浏览器实时录音，自动检测说话结束，把音频发给后端做语音识别，返回文字后自动发起聊天。

## 二、使用了什么技术

| 技术 | 用途 |
|------|------|
| `@ricky0123/vad-web` | 浏览器端 VAD（语音活动检测，Voice Activity Detection——自动判断"用户开始说话了"和"用户说完了"），基于 ONNX Runtime 在浏览器内运行 AI 模型，不需要服务端参与（什么是ONNX Runtime？一个跨平台的AI模型运行引擎。通常AI模型需要在服务器上用Python跑，但ONNX Runtime能把训练好的模型转成一种通用格式，在浏览器里直接用用户的CPU/GPU跑。这里的VAD模型就是一个小型的神经网络，能实时分析麦克风音频判断有没有人声——整个过程都在用户电脑上完成，不经过服务器，保护隐私且零延迟） |
| `MicVAD.new()` | VAD 库的初始化方法，配置语音起止检测参数和回调 |
| `Float32Array → Int16Array` | VAD 输出 Float32 音频采样，后端 ASR 需要 PCM 16-bit 格式，需要转换（什么是PCM？Pulse Code Modulation，脉冲编码调制——数字音频最原始的格式。简单说就是把声音波形每隔一小段时间量一次"高度"（采样），用数字记录下来。16-bit表示每个采样用16个二进制位记录（范围-32768到32767），Float32是用32位浮点数记录（范围-1.0到1.0）。VAD库吐出来的是Float32格式（数值在小数范围内），但阿里云语音识别API要的是16-bit整数格式——所以需要把每个采样从"-1.0到1.0"映射到"-32768到32767"，从浮点数变成整数。就像把温度从摄氏度转成华氏度——信息是一样的，只是表示方式不同） |
| `crypto.randomUUID()` | 浏览器原生 UUID 生成，给每条消息唯一标识用于 Vue 的 `:key` |
| `processId` 自增计数器 | 取消机制的实现——用户说新话时旧流自动作废，防止过时回复覆盖当前对话 |
| `v-if` / `v-else` 模式切换 | 文本输入框和语音输入条二选一显示，通过 `showMic` 布尔值控制 |
| CSS `@keyframes` 动画 | 32 根蓝色竖条的波浪跳动动画，视觉反馈"正在听你说话" |

### 4.4 `InputField.vue`——输入组件改造（46 行改动）

这是本次改动最大的文件。原来 `InputField` 只有文本输入，现在要**同时支持文本和语音两种输入模式**。

#### 4.4.1 import 新增 + 变量改造

```diff
+import Microphone from "@/components/character/chat_field/input_field/Microphone.vue";

 const props = defineProps(['friendId'])
 const emit = defineEmits(['pushBackMessage', 'addToLastMessage'])
 const inputRef = useTemplateRef('input-ref')
 const message = ref('')
-let isProcessing = false
+let processId = 0
+const showMic = ref(false)
```

**逐行讲解**：

- `import Microphone from "..."` —— 引入语音输入子组件
- `let isProcessing = false` → **删除**。之前用 `isProcessing` 布尔值防止重复发送（true=正在处理中，不允许再发）。现在改为 `processId` 计数器
- `let processId = 0` —— **自增 ID 取消机制**。每次新消息（或新语音输入）时 `processId` +1。发送消息时记录当前的 `processId` 到局部变量 `curId`。当流式回调触发时，先判断 `curId !== processId`——如果不相等说明有更新的消息顶掉了当前消息，直接 return 丢弃过期回调。这比布尔值更灵活：用户说了一句语音 → 立刻又说一句 → 第一句的回调自动作废
- `const showMic = ref(false)` —— 响应式布尔值。`false` = 显示文本输入框，`true` = 显示语音输入条

#### 4.4.2 `handleSend` 重构——支持语音消息输入

**改之前**：
```javascript
async function handleSend() {
  if (isProcessing) return
  isProcessing = true

  const content = message.value.trim()
  if (!content) return
  message.value = ''
  // ...streamApi...
}
```

**改之后**：
```javascript
async function handleSend(event, audio_msg) {
  let content
  if (audio_msg) {
    content = audio_msg.trim()
  } else {
    content = message.value.trim()
  }
  if (!content) return

  const curId = ++ processId
  message.value = ''

  emit('pushBackMessage', {role: 'user', content: content, id: crypto.randomUUID()})
  emit('pushBackMessage', {role: 'ai', content: '', id: crypto.randomUUID()})

  try {
    await streamApi('/api/friend/message/chat/', {
      body: {
        friend_id: props.friendId,
        message: content,
      },
      onmessage(data, isDone) {
        if (curId !== processId) return

        if (data.content) {
          emit('addToLastMessage', data.content)
        }
      },
      onerror(err) {
      },
    })
  } catch (err) {
  }
}
```

**逐行讲解**：

- `async function handleSend(event, audio_msg)` —— 新增第二个参数 `audio_msg`。文本模式：`@submit.prevent="handleSend"` 触发，只传 event，`audio_msg` 为 `undefined`。语音模式：子组件 `emit('send', null, data.text)` 调用，第二个参数传识别出的文字
- `if (audio_msg) { content = audio_msg.trim() } else { content = message.value.trim() }` —— 判断消息来源。有 `audio_msg`（语音识别结果）→ 用它；没有（文本输入）→ 取输入框的值
- `const curId = ++ processId` —— **先自增再赋值**。`++processId` 是前置自增，先 +1 再返回新值。`curId` 记录"本条消息的编号"
- `message.value = ''` —— 清空输入框（文本模式才有意义，语音模式下输入框本来就是空的）
- `if (curId !== processId) return` —— **取消检查**。用户在等 AI 回复时又发了一条新消息 → `processId` 已递增 → 旧回调的 `curId` 和当前 `processId` 不相等 → `return` 丢弃。**这样旧消息的回调不会追加到新消息的 AI 回复上**
- `onerror(err) {}` —— 错误处理从 `isProcessing = false` 改为空函数。因为不再用布尔值控制发送，而是用 `processId`。错误发生时不需要解锁发送按钮
- `catch (err) {}` —— 原来也有 `isProcessing = false`，现在同样移除

### 4.5 `Microphone.vue`——语音输入组件（107行，新文件）

完整代码：

```vue
<script setup>
import KeyboardIcon from "@/components/character/icons/KeyboardIcon.vue";
import {onBeforeUnmount, onMounted, ref} from "vue";
import {MicVAD} from "@ricky0123/vad-web";
import api from "@/js/http/api.js";

const emit = defineEmits(['close', 'send', 'stop'])
const isSpeaking = ref(false)

let vadInstance = null;

const startRecording = async () => {
  const baseUrl = "http://localhost:5173/vad/";
  try {
    vadInstance = await MicVAD.new({
      baseAssetPath: baseUrl,
      onSpeechStart: () => {
        isSpeaking.value = true;
        emit('stop')
      },
      onSpeechEnd: (audio) => {
        isSpeaking.value = false;
        const pcm16 = float32ToInt16(audio);
        sendToBackend(pcm16);
      },
      ortConfig: (ort) => {
        ort.env.wasm.wasmPaths = baseUrl;
        ort.env.logLevel = "error";
      },
      positiveSpeechThreshold: 0.8,
      negativeSpeechThreshold: 0.65,
      minSpeechFrames: 5,
      redemptionFrames: 5,
    });

    await vadInstance.start();
  } catch (e) {
    console.error("VAD 初始化失败:", e);
  }
};
// 将 Float32 转 PCM 16-bit
const float32ToInt16 = (float32Array) => {
  const buffer = new Int16Array(float32Array.length);
  for (let i = 0; i < float32Array.length; i++) {
    let s = Math.max(-1, Math.min(1, float32Array[i]));
    buffer[i] = s < 0 ? s * 0x8000 : s * 0x7fff;
  }
  return buffer.buffer;
};

const sendToBackend = async (arrayBuffer) => {
  const blob = new Blob([arrayBuffer], { type: "audio/pcm" })
  const formData = new FormData()
  formData.append("audio", blob, 'voice.pcm')

  try {
    const res = await api.post('', formData)
    const data = res.data
    if (data.result === 'success') {
      emit('send', null, data.text)
    }
  } catch (err) {
    console.error(err)
  }
};

onMounted(() => {
  startRecording()
})

onBeforeUnmount(() => {
  if (vadInstance) {
    vadInstance.destroy()
    vadInstance = null
  }
})
</script>

<template>
  <div class="absolute bottom-4 left-2 h-12 w-86 flex items-center bg-black/30 backdrop-blur-sm rounded-2xl">
    <div v-if="isSpeaking" class="flex items-center justify-center gap-1 h-6 flex-1">
      <div
        v-for="i in 32" :key="i"
        class="w-0.5 bg-blue-400 rounded-full animate-wave"
        :style="{ animationDelay: `${i * 0.1}s` }"
      ></div>
    </div>
    <div v-else class="text-white/50 text-base w-full text-center">
      语音输入
    </div>
    <div @click="emit('close')" class="absolute right-2 w-8 h-8 flex justify-center items-center cursor-pointer">
      <KeyboardIcon />
    </div>
  </div>
</template>

<style scoped>
.animate-wave {
  height: 4px;
  animation: wave-animation 0.6s ease-in-out infinite alternate;
}

@keyframes wave-animation {
  0% { height: 4px; opacity: 0.3; }
  100% { height: 20px; opacity: 1; }
}
</style>
```

#### 逐段讲解

**Script 部分：**

- `import { MicVAD } from "@ricky0123/vad-web"` —— 导入 VAD 库的 `MicVAD` 类。VAD = Voice Activity Detection（语音活动检测）
- `const emit = defineEmits(['close', 'send', 'stop'])` —— 声明三个事件。`close`（切回键盘）、`send`（识别完成发消息）、`stop`（开始说话取消旧流）
- `const isSpeaking = ref(false)` —— 响应式状态。true 时显示动画条，false 时显示"语音输入"文字
- `let vadInstance = null` —— 保存 VAD 实例引用，销毁时用

**`startRecording()` 函数：**

- `const baseUrl = "http://localhost:5173/vad/"` —— VAD 的 ONNX 模型文件从 Vite 开发服务器加载。`MicVAD` 启动时会自动下载 `silero_vad.onnx` 等模型文件到这个路径
- `MicVAD.new({...})` —— 初始化 VAD 实例，配置参数和回调：
  - `baseAssetPath: baseUrl` —— 模型文件的 URL 前缀
  - `onSpeechStart: () => { ... }` —— 检测到用户开始说话时触发。`isSpeaking.value = true` 切换到动画；`emit('stop')` 通知父组件取消旧流
  - `onSpeechEnd: (audio) => { ... }` —— 检测到用户说完话时触发。参数 `audio` 是 `Float32Array` 格式的 PCM 音频采样。先转 Int16 格式，再发给后端。**这里不需要手动开始/停止录音**——VAD 库自动管理麦克风权限和录音
  - `ortConfig: (ort) => { ... }` —— ONNX Runtime 配置。`wasmPaths` 指定 WebAssembly 文件的路径；`logLevel: "error"` 只输出错误日志，不输出调试信息
  - `positiveSpeechThreshold: 0.8` —— 置信度阈值，当模型判断"有语音"的概率 > 0.8 时才触发 `onSpeechStart`。数值越高越不容易误触发（但可能漏掉轻声细语的说话）
  - `negativeSpeechThreshold: 0.65` —— 置信度阈值，当模型判断"无语音"的概率 > 0.65 时才触发 `onSpeechEnd`。数值越低停顿越久才判定结束
  - `minSpeechFrames: 5` —— 至少持续 5 帧（每帧约 30ms，共约 150ms）声音才认为"开始说话"。防止咳嗽、敲键盘等短促声音误触发
  - `redemptionFrames: 5` —— 判断说话结束后，回退 5 帧作为语音结束点。防止把最后一个字的尾音截掉
- `await vadInstance.start()` —— 启动 VAD，开始监听麦克风

**`float32ToInt16()` 函数：**

- `new Int16Array(float32Array.length)` —— Int16Array 是一个有符号 16 位整数数组（范围 -32768 ~ 32767），每个元素占 2 字节
- `Math.max(-1, Math.min(1, float32Array[i]))` —— **限幅（clamp）**。把浮点数限制在 [-1, 1] 范围内，防止采样溢出
- `s < 0 ? s * 0x8000 : s * 0x7fff` —— 线性映射：[-1, 0) → [-32768, 0)，[0, 1] → [0, 32767]。`0x8000` = 32768，`0x7fff` = 32767
- `return buffer.buffer` —— 返回 `ArrayBuffer`（底层二进制数据），用于构造 Blob

**`sendToBackend()` 函数：**

- `new Blob([arrayBuffer], { type: "audio/pcm" })` —— 创建 PCM 音频的 Blob 对象。`type: "audio/pcm"` 告诉服务器这是什么格式
- `formData.append("audio", blob, 'voice.pcm')` —— 把 Blob 加到 FormData，第三个参数是文件名
- `await api.post('', formData)` —— **注意：URL 是空字符串！** 这是一个 bug——后面提交会修复为 `'/api/friend/message/asr/asr/'`。当前版本语音识别实际上发不出去，但不影响文本输入功能
- `emit('send', null, data.text)` —— 识别成功，把文字 emit 给父组件。第一个参数是事件对象（传 null），第二个参数是识别出的文字（作为 `handleSend` 的第二个参数 `audio_msg`）

**`onMounted` 和 `onBeforeUnmount`：**

- `onMounted(() => { startRecording() })` —— 组件挂载到 DOM 后立即开始监听麦克风。不需要用户手动点"开始录音"——进入语音模式后自动开始
- `onBeforeUnmount(() => { vadInstance.destroy() })` —— 组件卸载前销毁 VAD 实例，释放麦克风权限和内存。否则麦克风指示灯可能一直亮着

**Template 部分：**

- `<div v-if="isSpeaking" class="flex items-center justify-center gap-1 h-6 flex-1">` —— 说话状态：水平居中排列 32 根动画竖条
- `v-for="i in 32"` —— 循环渲染 32 根竖条。`i` 从 1 到 32
- `class="w-0.5 bg-blue-400 rounded-full animate-wave"` —— 每根条宽 2px（`w-0.5`），蓝色，圆头，应用 `animate-wave` 动画
- `:style="{ animationDelay: \`${i * 0.1}s\` }"` —— **错峰延迟**。每根条延迟递增 0.1 秒（第 1 根 0s，第 32 根 3.2s），形成波浪起伏的视觉效果
- `<div v-else class="text-white/50 text-base w-full text-center">语音输入</div>` —— 空闲状态（没检测到声音时）：显示半透明白色"语音输入"文字
- `<div @click="emit('close')">` —— 点击键盘图标 → emit('close') → 父组件 `showMic = false` → 切回文本输入框
- `<KeyboardIcon />` —— 键盘图标组件

**Style 部分：**

```css
.animate-wave {
  height: 4px;
  animation: wave-animation 0.6s ease-in-out infinite alternate;
}

@keyframes wave-animation {
  0% { height: 4px; opacity: 0.3; }
  100% { height: 20px; opacity: 1; }
}
```

- `animation: wave-animation 0.6s ease-in-out infinite alternate` —— 动画名 + 0.6 秒周期 + 缓入缓出 + 无限循环 + 来回交替（正向长高、反向缩矮）
- `@keyframes wave-animation` —— 动画关键帧。0% 时高 4px 半透明 → 100% 时高 20px 完全不透明。配合 `alternate`，竖条会从矮→高→矮→高……持续跳动
