## 二、`ASRView`——语音识别 API

**文件**：`backend/web/views/friend/message/asr/asr.py`（新文件）

```python
class ASRView(APIView):
    permission_classes = [IsAuthenticated]
    def post(self, request):
        audio = request.FILES.get('audio')
        pcm_data = audio.read()                     # 读取完整PCM数据
        text = asyncio.run(self.run_asr_tasks(pcm_data))  # 同步转异步
        return Response({'result': 'success', 'text': text})
```

**Django 同步视图里调异步代码**：`asyncio.run()` 在同步函数中运行异步协程，创建一个新事件循环，等协程结束返回结果。

### WebSocket 双向流式通信

```python
async def asr_sender(self, pcm_data, ws, task_id):
    chunk = 3200       # 每次发3200字节（约100ms的PCM数据）
    for i in range(0, len(pcm_data), chunk):
        await ws.send(pcm_data[i: i + chunk])
        await asyncio.sleep(0.01)   # 模拟实时流，控制发送速率
```

语音识别服务期望**流式**接收音频——像人说话一样逐步到达，而不是一次收到完整文件。

```python
async def asr_receiver(self, ws):
    text = ''
    async for msg in ws:
        event = data['header']['event']
        if event == 'result-generated':
            output = data['payload']['output']
            if output.get('transcription', {})['sentence_end']:
                text += output['transcription']['text']
```

`transcription['sentence_end']` 标记一句话是否结束。只取句子结束的结果——中间临时结果忽略，防止重复。

### WebSocket 协议

```
客户端                    ASR 服务
   │                         │
   ├── run-task ────────────→│  启动识别任务
   │←── task-started ────────│  任务已开始
   │                         │
   ├── PCM chunk 1 ─────────→│  流式发送音频
   ├── PCM chunk 2 ─────────→│
   ├── ...                   │
   ├── finish-task ─────────→│  音频发送完毕
   │                         │
   │←── result-generated ────│  识别到文字
   │←── task-finished ───────│  识别完成
```
