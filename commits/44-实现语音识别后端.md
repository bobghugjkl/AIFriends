## 一、这次提交做了什么

实现了 **ASR（自动语音识别）后端 API**——前端发来 PCM 音频文件，后端通过 WebSocket 连接阿里云百炼的实时语音识别服务，流式发送音频、流式接收识别结果，最终返回完整文字。（什么是WebSocket？一种"双向实时通信"协议。普通的HTTP像寄信——你发一封，对方回一封，每封信都是独立的，寄完就完了。WebSocket像打电话——先拨号建立连接，然后双方可以随时说话、随时听，连接一直保持直到挂断。HTTP的请求-响应模式不适合实时语音识别——因为音频数据是持续不断的流，你不能每个音频片段都发一个新HTTP请求（太慢、太浪费）。WebSocket只需要建立一次连接，然后像水管一样，音频数据从这头灌进去，识别结果从那头流出来，直到所有音频处理完才关闭连接。`ws://`开头是WebSocket地址，就像`http://`开头是网页地址）

## 二、使用了什么技术

| 技术 | 用途 |
|------|------|
| `websockets` 库 | Python 异步 WebSocket 客户端 |
| `asyncio.run()` | Django 同步视图 → 异步协程的桥接（什么是协程coroutine？Python中一种特殊的函数，用`async def`定义，可以在执行到一半时"暂停"去干别的事，等条件满足再回来继续。普通函数像一个不能中断的任务——必须从头到尾一口气执行完；协程像一个可以暂停的任务——执行到`await`时主动让出控制权，Python去处理其他协程，等`await`的东西有结果了再切回来。打个比方：普通函数像在ATM排队——后面的人必须等你操作完；协程像在饭店点餐——你点完菜不用站柜台等，服务员（事件循环）去通知厨房做菜，你去坐着，菜好了服务员叫你。`asyncio.run()`就是把一个协程放在事件循环里运行——Django的视图是普通同步函数，但WebSocket操作是异步协程，`asyncio.run()`就是这两个世界之间的翻译官） |
| `asyncio.gather()` | 并发执行发送和接收协程（什么是并发执行？WebSocket场景下有两个任务需要同时进行：一边不断发送音频数据（sender），一边不断接收识别结果（receiver）。如果用普通函数顺序执行，只能"发完再收"——但发送完所有音频后才开始接收的话，中间返回的识别结果就全丢了。`asyncio.gather(sender, receiver)`让两个协程"同时"运行——Python在两个任务之间快速切换，哪个有数据就处理哪个。虽然不是真正的并行（同时用两个CPU核），但对于IO密集型任务（网络收发），这种并发完全够用。就像一个人同时看两个聊天窗口——左窗口有新消息就回左窗口，右窗口有新消息就回右窗口，来回切换，两个窗口都不会错过消息） |
| WebSocket 双向流协议 | run-task → task-started → continue-task(+PCM) → finish-task → result-generated → task-finished |
| `gummy-realtime-v1` | 阿里云百炼实时语音识别模型 |
| PCM 16kHz 16-bit | 音频格式，16000 采样率，每次发 3200 字节 |

## 三、整体架构

```
Django ASRView.post()
    │
    ├── audio.read() → 完整 PCM 字节
    └── asyncio.run(run_asr_tasks(pcm_data))
            │
            ▼
        WebSocket 连接阿里云 ASR 服务
            │
            ├── send: run-task (model=gummy-realtime-v1)
            ├── recv: task-started
            │
            ├── asyncio.gather(
            │       asr_sender(pcm, ws),    ← 流式发送音频
            │       asr_receiver(ws),       ← 流式接收识别结果
            │   )
            │
            └── return 完整识别文字
```

## 四、源码（`asr.py`，新文件，94行）

```python
import asyncio
import json
import os
import uuid

import websockets
from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework.permissions import IsAuthenticated


class ASRView(APIView):
    permission_classes = [IsAuthenticated]

    def post(self, request):
        audio = request.FILES.get('audio')
        if not audio:
            return Response({
                'result': '音频不存在'
            })
        pcm_data = audio.read()
        text = asyncio.run(self.run_asr_tasks(pcm_data))
        return Response({
            'result': 'success',
            'text': text,
        })


    async def asr_sender(self, pcm_data, ws, task_id):
        chunk = 3200
        for i in range(0, len(pcm_data), chunk):
            await ws.send(pcm_data[i: i + chunk])
            await asyncio.sleep(0.01)
        await ws.send(json.dumps({
            "header": {
                "action": "finish-task",
                "task_id": task_id,
                "streaming": "duplex"
            },
            "payload": {
                "input": {}
            }
        }))


    async def asr_receiver(self, ws):
        text = ''
        async for msg in ws:
            data = json.loads(msg)
            event = data['header']['event']
            if event == 'result-generated':
                output = data['payload']['output']
                if output.get('transcription', None) and output['transcription']['sentence_end']:
                    text += output['transcription']['text']
            elif event in ['task-finished', 'task-failed']:
                break
        return text


    async def run_asr_tasks(self, pcm_data):
        task_id = uuid.uuid4().hex
        api_key = os.getenv('API_KEY')
        wss_url = os.getenv('WSS_URL')
        headers = {
            "Authorization": f"Bearer {api_key}"
        }
        async with websockets.connect(wss_url, additional_headers=headers) as ws:
            await ws.send(json.dumps({
                "header": {
                    "streaming": "duplex",
                    "task_id": task_id,
                    "action": "run-task"
                },
                "payload": {
                    "model": "gummy-realtime-v1",
                    "parameters": {
                        "sample_rate": 16000,
                        "format": "pcm",
                        "transcription_enabled": True,
                    },
                    "input": {},
                    "task": "asr",
                    "task_group": "audio",
                    "function": "recognition"
                }
            }))
            async for msg in ws:
                if json.loads(msg)['header']['event'] == 'task-started':
                    break
            _, text = await asyncio.gather(
                self.asr_sender(pcm_data, ws, task_id),
                self.asr_receiver(ws),
            )
            return text
```

### 逐段讲解

#### `post()`——Django 同步入口

```python
def post(self, request):
    audio = request.FILES.get('audio')
    if not audio:
        return Response({'result': '音频不存在'})
    pcm_data = audio.read()
    text = asyncio.run(self.run_asr_tasks(pcm_data))
    return Response({'result': 'success', 'text': text})
```

- `request.FILES.get('audio')` —— 前端通过 FormData 上传的 PCM 音频文件
- `audio.read()` —— 读取全部字节到内存。前端 VAD 一次只录一句话（通常 1-5 秒），文件很小，全读没问题
- `asyncio.run(self.run_asr_tasks(pcm_data))` —— **同步 → 异步桥接**。`asyncio.run()` 在同步函数中创建新的事件循环，运行异步协程，等协程结束后返回结果。Django 视图是同步的，但 WebSocket 需要异步，`asyncio.run()` 是标准桥接方案

#### `asr_sender()`——流式发送音频

```python
async def asr_sender(self, pcm_data, ws, task_id):
    chunk = 3200
    for i in range(0, len(pcm_data), chunk):
        await ws.send(pcm_data[i: i + chunk])
        await asyncio.sleep(0.01)
    await ws.send(json.dumps({
        "header": {
            "action": "finish-task",
            "task_id": task_id,
            "streaming": "duplex"
        },
        "payload": {"input": {}}
    }))
```

- `chunk = 3200` —— 每次发送 3200 字节。PCM 16kHz 16-bit 单声道：每秒 = 16000 × 2 字节 = 32000 字节。3200 字节 ≈ 100ms 音频。每次发 100ms 的数据块模拟实时说话
- `for i in range(0, len(pcm_data), chunk)` —— 分块遍历。`range(start, stop, step)` 从 0 到文件大小，步长 3200
- `await ws.send(pcm_data[i: i + chunk])` —— 发送一个音频块。切片语法 `[start:end]`，最后一块可能不足 3200 字节
- `await asyncio.sleep(0.01)` —— **控制发送速率**。不休眠的话会瞬间把整段音频发出——ASR 服务期望流式速率，太快可能丢数据或误判
- 最后发送 `finish-task` —— 告诉 ASR 服务"我说完了，请返回最终结果"

#### `asr_receiver()`——流式接收识别结果

```python
async def asr_receiver(self, ws):
    text = ''
    async for msg in ws:
        data = json.loads(msg)
        event = data['header']['event']
        if event == 'result-generated':
            output = data['payload']['output']
            if output.get('transcription', None) and output['transcription']['sentence_end']:
                text += output['transcription']['text']
        elif event in ['task-finished', 'task-failed']:
            break
    return text
```

- `async for msg in ws` —— 异步迭代 WebSocket 消息流。每收到一条就处理，直到连接关闭
- `event == 'result-generated'` —— ASR 每次识别出文字时触发。**注意**：实时 ASR 会多次触发（用户继续说话，不断更新识别结果）
- `output.get('transcription', None)` —— 安全取嵌套字段。`transcription` 可能为空
- `output['transcription']['sentence_end']` —— **关键过滤**！ASR 实时模式下每识别出新词都会触发 `result-generated`。但很多是中间结果（如说了"今天"→ 临时结果是"今天"→ 又说"天气"→ 更新为"今天天气"）。`sentence_end = True` 表示这句话已经说完，文本是最终结果。只取最终结果避免了重复文字
- `text += output['transcription']['text']` —— 追加到累积文本
- `event in ['task-finished', 'task-failed']` —— 识别结束或失败，退出循环

- `uuid.uuid4().hex` —— 生成 32 位随机十六进制字符串（如 `a1b2c3d4e5f6...`），作为本次识别任务的唯一 ID
- `websockets.connect(wss_url, additional_headers=headers)` —— 建立 WebSocket 连接。`wss://` 协议（WebSocket Secure = WebSocket over TLS），`additional_headers` 传认证信息

**发送 run-task：**

```python
        await ws.send(json.dumps({
            "header": {
                "streaming": "duplex",
                "task_id": task_id,
                "action": "run-task"
            },
            "payload": {
                "model": "gummy-realtime-v1",
                "parameters": {
                    "sample_rate": 16000,

                "task": "asr",
                "task_group": "audio",
                "function": "recognition"
            }

```

- `"streaming": "duplex"` —— 双向流模式。客户端发音频流 + 服务端返回识别结果流
- `"model": "gummy-realtime-v1"` —— 阿里云百炼的**实时**语音识别模型
- `"sample_rate": 16000` —— 采样率 16kHz。前端 VAD 录制时也设为 16kHz，必须一致
- `"format": "pcm"` —— 原始 PCM 格式（无压缩编码如 MP3/AAC）
- `"transcription_enabled": True` —— 开启文字转写

**等待任务启动 + 并发发送/接收：**

```python
        async for msg in ws:
            if json.loads(msg)['header']['event'] == 'task-started':
                break
        _, text = await asyncio.gather(
            self.asr_sender(pcm_data, ws, task_id),
```

- `async for msg in ws: if ... 'task-started': break` —— 等待服务端确认任务已创建。收到 `task-started` 后才开始发音频。如果在 `task-started` 之前就发音频，服务端可能忽略
- `asyncio.gather(sender, receiver)` —— **并发执行**两个协程。sender 逐块发音频，receiver 逐条收识别结果，两个操作交替进行（不是串行——不需要等发完才开始收）。`gather` 返回一个元组 `(sender返回值, receiver返回值)`，用 `_` 丢弃 sender 返回值（sender 没有返回值）
- `return text` —— receiver 返回的完整识别文字

## 五、总结

| 方法 | 职责 | 关键逻辑 |
|------|------|---------|
| `post()` | Django 入口 | `asyncio.run()` 桥接同步→异步 |
| `asr_sender()` | 发音频流 | 3200 字节分块 + 10ms 间隔模拟实时 |
| `asr_receiver()` | 收识别结果 | `sentence_end` 过滤中间结果，只取最终文字 |
| `run_asr_tasks()` | 编排 WebSocket | run-task → task-started → gather(send, recv) → return text |
