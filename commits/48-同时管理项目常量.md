## 一、前端配置文件集中管理

**文件**：`frontend/src/js/config/config.js`（新文件）

```javascript
const platform = 'django'   // vue（开发）、django（本地部署）、cloud（云端）

    HTTP_URL: '',
    VAD_URL: '',
}

if (platform === 'vue') {
    CONFIG_API.HTTP_URL = 'http://127.0.0.1:8000'
    CONFIG_API.VAD_URL = 'http://localhost:5173/vad/'
} else if (platform === 'django') {
    CONFIG_API.HTTP_URL = 'http://127.0.0.1:8000'
    CONFIG_API.VAD_URL = 'http://127.0.0.1:8000/static/frontend/vad/'
} else if (platform === 'cloud') {
    CONFIG_API.HTTP_URL = 'https://app7492.acapp.acwing.com.cn'
    CONFIG_API.VAD_URL = 'https://app7492.acapp.acwing.com.cn/static/frontend/vad/'

```

## 二、settings.py 支持生产/开发双模式

```python
ALLOWED_HOSTS = ['127.0.0.1', 'app7492.acapp.acwing.com.cn']  # 允许域名

if not DEBUG:
    STATIC_ROOT = BASE_DIR / 'static'     # 生产：Django收集静态文件
else:
    STATICFILES_DIRS = [BASE_DIR / 'static']  # 开发：直接从这里找

if DEBUG:
    MEDIA_URL = 'http://127.0.0.1:8000/media/'
else:
    MEDIA_URL = 'https://app7492.acapp.acwing.com.cn/media/'
```

**`DEBUG` 为 `True`（开发）和 `False`（生产）时的区别**：

| 配置 | 开发（DEBUG=True） | 生产（DEBUG=False） |
|------|-------------------|---------------------|
| 静态文件 | `STATICFILES_DIRS`——直接从目录读取 | `STATIC_ROOT`——需先 `collectstatic` |
| MEDIA_URL | 本地 `127.0.0.1:8000` | 云端完整域名 |
| ALLOWED_HOSTS | 允许本地和云端 | 同左 |
