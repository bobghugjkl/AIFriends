## 一、这次提交做了什么

创建了 `Message` 模型——存储用户和 AI 角色的**聊天记录**。每条消息记录用户说了什么、AI 回复了什么、发送给 AI 的完整输入（含系统提示词+历史）、token 消耗量。

## 三、整体架构 / 数据流

```
Message Model (消息)
  │
  ├── friend ──ForeignKey──► Friend ──ForeignKey──► Character
  │                              (好友关系)            (AI角色)
  │
  ├── user_message     用户输入的原文（用于聊天展示）
  ├── input            发送给 AI 的完整内容（含系统提示词+历史）
  ├── output           AI 回复的文本
  ├── input_tokens     API 请求消耗的 token 数
  ├── output_tokens    API 回复消耗的 token 数
  └── total_tokens     总 token 消耗 = input + output

  token_tracking → API cost monitoring
```

## 四、修改文件：`backend/web/models/friend.py` —— 新增 Message 模型

**路径**：`backend/web/models/friend.py`

**本次提交在 Friend 模型之后新增的 Message 模型完整源码：**

```python
class Message(models.Model):
    friend = models.ForeignKey(Friend, on_delete=models.CASCADE)
    user_message = models.TextField(max_length=500)
    input = models.TextField(max_length=500)
    output = models.TextField(max_length=500)
    input_tokens = models.IntegerField(default=0)
    output_tokens = models.IntegerField(default=0)
    total_tokens = models.IntegerField(default=0)
    create_time = models.DateTimeField(default=now)

    def __str__(self):
        return f"{self.friend.character.name} - {self.friend.me.user.username} - {self.user_message[:50]} - {localtime(self.create_time).strftime('%Y-%m-%d %H:%M:%S')}"
```

**逐字段讲解：**

| 字段 | 类型 | 用途 |
|------|------|------|
| `friend` | `ForeignKey(Friend)` | 外键指向 Friend。每条消息属于某个好友关系。`Message -> Friend -> Character`，知道这条消息是和哪个角色说的 |
| `user_message` | `TextField(max_length=500)` | 用户输入的文本（最长 500 字） |
| `input` | `TextField(max_length=500)` | 发送给 AI 的完整输入。不只有用户的话，还包括系统提示词、历史对话等。存这个方便调试和回查 |
| `output` | `TextField(max_length=500)` | AI 回复的文本（最长 500 字） |
| `input_tokens` | `IntegerField(default=0)` | API 请求消耗的 token 数 |
| `output_tokens` | `IntegerField(default=0)` | API 回复消耗的 token 数 |
| `total_tokens` | `IntegerField(default=0)` | 总 token 消耗 = input + output |
| `create_time` | `DateTimeField(default=now)` | 消息创建时间 |

## 五、Admin 注册

在 `admin.py` 中注册 Message 模型以便在 Django Admin 后台查看和管理：

```python
@admin.register(Message)
class MessageAdmin(admin.ModelAdmin):
    raw_id_fields = ('friend',)
```

`raw_id_fields` —— 外键字段太多时，Django Admin 默认显示下拉框。数据量大时下拉框加载慢。`raw_id_fields` 改为显示 ID 输入框 + 搜索图标，输入框可以直接填 ID，搜索图标弹出搜索窗口。性能更好。
