## 二、Message 模型

**文件**：`backend/web/models/friend.py`（追加在 Friend 模型后面）

```python
class Message(models.Model):
    friend = models.ForeignKey(Friend, on_delete=models.CASCADE)
    user_message = models.TextField(max_length=500)
    input = models.TextField(max_length=500)
    output = models.TextField(max_length=500)
    input_tokens = models.IntegerField(default=0)
    output_tokens = models.IntegerField(default=0)
    total_tokens = models.IntegerField(default=0)
    create_time = models.DateTimeField(default=now)
```

**逐字段讲解**：

- `friend` —— **外键指向 Friend**。每条消息属于某个好友关系。`Message → Friend → Character`，知道这条消息是和哪个角色说的
- `user_message` —— 用户输入的文本（最长 500 字）
- `input` —— **发送给 AI 的完整输入**。不只有用户的话，还包括系统提示词、历史对话等。存这个方便调试和回查
- `output` —— AI 回复的文本（最长 500 字）
- `input_tokens` / `output_tokens` / `total_tokens` —— token 消耗量。AI API 按 token 计费，记录这个可以统计每个用户花了多少钱

**`.gitignore` 新增**：`*.env`——环境变量文件（API_KEY 等敏感信息）不提交到 Git。

## 四、总结

| 字段 | 存什么 | 为什么存 |
|------|--------|---------|
| `friend` | 好友关系 | 知道消息属于哪个对话 |
| `user_message` | 用户原文 | 聊天记录展示 |
| `input` | 发给 AI 的完整内容 | 调试 + 下次对话的历史上下文 |
| `output` | AI 回复 | 聊天记录展示 |
| `*_tokens` | token 数 | 统计 API 费用 |
