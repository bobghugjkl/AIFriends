## 一、这次提交做了什么

给聊天消息增加 **TTS（文本转语音）**——AI 生成文字的同时，把文字流式发给阿里云百炼的 `cosyvoice-v3-flash` 语音合成服务，合成出的 MP3 音频通过 SSE 推给前端实时播放。用户不仅能看 AI 回复，还能听到 AI "说话"。

---

## 二、使用了什么技术

| 技术 | 用途 |
|------|------|
| Python `queue.Queue` | 线程安全消息队列，同步主线程和异步工作线程的通信桥梁（什么是线程？一个程序可以同时运行多个"执行路径"，每个路径就叫一个线程。主线程处理HTTP请求和SSE推送，工作线程运行WebSocket连接阿里云TTS——两个线程同时工作、互不阻塞。如果不用线程，WebSocket的异步事件循环会占用主线程，导致Django无法响应其他请求。`queue.Queue`是两个线程之间的"传送带"——工作线程把AI文字和合成音频放到队列里，主线程从队列里取出来通过SSE推给前端。Queue是线程安全的，保证多线程同时读写不会出现数据错乱。打个比方：主线程是前台服务员，工作线程是后厨——前台接单后通知后厨开始做菜（启动线程），后厨做好一道菜就放到传菜窗口（Queue），前台从窗口取菜端给客人（SSE推送），两方不需要面对面交流，通过传菜窗口（Queue）异步协作） |
| `threading.Thread` | 独立线程运行异步事件循环，不阻塞 Django 主线程 |
| `asyncio.run()` | 在线程中创建事件循环，运行 WebSocket 协程 |
| `websockets` 库 | 异步连接阿里云 TTS WebSocket 服务 |
| `app.astream()` | LangGraph 异步流式生成器（代替 `app.stream()`），在协程中逐 token 产文本 |
| `asyncio.gather()` | 并发执行 sender（发文本收音频）和 receiver（收音频） |
| `base64.b64encode` | 二进制 MP3 编码为 Base64 字符串，通过 SSE JSON 传输 |
| `cosyvoice-v3-flash` | 阿里云百炼流式 TTS 模型 |

## 三、整体架构

```
Main Thread (Django)                  Worker Thread (asyncio)
        │                                      │
        ├── Queue() + Thread.start() ──────────→│
        │                                      │
        │                            asyncio.run(run_tts_tasks)
        │                                      │
        │                            WebSocket connect TTS
        │                            send: run-task (cosyvoice-v3-flash)
        │                            recv: task-started
        │                                      │
        │                          ┌─ asyncio.gather ─┐
        │                          │                  │
        │                     tts_sender          tts_receiver
        │                     (发AI文字)          (收MP3音频)
        │                          │                  │
        │                  app.astream()        async for msg:
        │                  yield text           if bytes→base64
        │                          │                  │
        │                  mq.put(content)     mq.put(audio)
        │                          │                  │
        ▼                          ▼                  ▼
    while True: ←─── mq.get() ──── 消息队列
        │
    if content → yield SSE text
    if audio   → yield SSE audio
    if None    → break (DONE + 存数据库)
```

### 4.3 `tts_sender()`——流式发文本给 TTS

```python
    async def tts_sender(self, app, inputs, mq, ws, task_id):
        async for msg, metadata in app.astream(inputs, stream_mode="messages"):
            if isinstance(msg, BaseMessageChunk):
                if msg.content:
                    await ws.send(json.dumps({
                        "header": {
                            "action": "continue-task",
                            "task_id": task_id,
                            "streaming": "duplex"
                        },
                        "payload": {
                            "input": {
                                "text": msg.content,
                            }
                        }
                    }))
                    mq.put_nowait({'content': msg.content})
                if hasattr(msg, 'usage_metadata') and msg.usage_metadata:
                    mq.put_nowait({'usage': msg.usage_metadata})
        await ws.send(json.dumps({
            "header": {
                "action": "finish-task",
                "task_id": task_id,
                "streaming": "duplex"
            },
            "payload": {
                "input": {}
            }
        }))
```

**逐行讲解**：

- `async def tts_sender(self, app, inputs, mq, ws, task_id):` —— 异步方法。参数：`app`=LangGraph 编译后的工作流，`inputs`=消息输入，`mq`=消息队列，`ws`=TTS WebSocket 连接，`task_id`=任务 UUID
- `async for msg, metadata in app.astream(inputs, stream_mode="messages"):` —— **异步流式调用 LangGraph**。`app.astream()` 是 `app.stream()` 的异步版本。因为整个 `tts_sender` 在 `asyncio` 事件循环中运行，必须用 `astream` 不能用 `stream`
- `await ws.send(json.dumps({...}))` —— 把 AI 生成的文字片段发给 TTS 服务合成语音。`action: "continue-task"` 表示"同一任务继续发数据"
- `mq.put_nowait({'content': msg.content})` —— 文字同时放入消息队列。`put_nowait` 是非阻塞入队（Queue 无界，不会满）
- `hasattr(msg, 'usage_metadata')` —— token 统计信息放入队列
- 循环结束后发送 `finish-task` —— 告诉 TTS 服务"没有更多文字了"，TTS 服务会返回 final 音频帧和 `task-finished`

**与 ASR sender 的对比**：

| | ASR sender | TTS sender |
|---|---|---|
| 发送内容 | PCM 音频字节 | JSON（含文本字段） |
| 发送速率 | 3200 字节/次 + 10ms sleep | 跟 AI 生成速度一致（无延迟） |
| 结束信号 | finish-task | finish-task |
| 数据来源 | 内存中的完整 PCM | LangGraph 实时生成的 token |

### 4.4 `tts_receiver()`——流式接收合成音频

```python
    async def tts_receiver(self, mq, ws):
        async for msg in ws:
            if isinstance(msg, bytes):
                audio = base64.b64encode(msg).decode('utf-8')
                mq.put_nowait({'audio': audio})
            else:
                data = json.loads(msg)
                event = data['header']['event']
                if event in ['task-finished', 'task-failed']:
                    break
```

**逐行讲解**：

- `async for msg in ws:` —— 迭代 WebSocket 收到的每条消息
- `isinstance(msg, bytes)` —— **关键判断**。WebSocket 消息有两种类型：二进制帧（`bytes`）= 音频数据，文本帧（`str`）= JSON 控制消息
- `base64.b64encode(msg).decode('utf-8')` —— 二进制 MP3 → Base64 字符串。`b64encode` 返回 `bytes`，`.decode('utf-8')` 转为 `str`。Base64 编码后的字符串可以通过 JSON 传输（二进制不能直接放 JSON）
- `mq.put_nowait({'audio': audio})` —— 编码后的音频放入队列
- 文本帧：解析 JSON → 检查 `event` → `task-finished`/`task-failed` → 退出循环

### 4.5 `run_tts_tasks()`——WebSocket 编排

```python
    async def run_tts_tasks(self, app, inputs, mq):
        task_id = uuid.uuid4().hex
        api_key = os.getenv('API_KEY')
        wss_url = os.getenv('WSS_URL')
        headers = {
            "Authorization": f"Bearer {api_key}"
        }
        async with websockets.connect(wss_url, additional_headers=headers) as ws:
            await ws.send(json.dumps({
                "header": {
                    "action": "run-task",
                    "task_id": task_id,
                    "streaming": "duplex"
                },
                "payload": {
                    "task_group": "audio",
                    "task": "tts",
                    "function": "SpeechSynthesizer",
                    "model": "cosyvoice-v3-flash",
                    "parameters": {
                        "text_type": "PlainText",
                        "voice": "longanyang",
                        "format": "mp3",
                        "sample_rate": 22050,
                        "volume": 50,
                        "rate": 1.25,
                        "pitch": 1
                    },
                    "input": {}
                }
            }))
            async for msg in ws:
                if json.loads(msg)['header']['event'] == 'task-started':
                    break
            await asyncio.gather(
                self.tts_sender(app, inputs, mq, ws, task_id),
                self.tts_receiver(mq, ws),
            )
```

**run-task 参数详解**：

- `"model": "cosyvoice-v3-flash"` —— 阿里云百炼的流式 TTS 模型。支持边收文本边合成
- `"voice": "longanyang"` —— **硬编码音色**。后续提交（#49）改为 `friend.character.voice.voice_id` 动态选择
- `"format": "mp3"` —— 输出 MP3 格式。MP3 是流式兼容格式，可以边收边解码播放
- `"sample_rate": 22050` —— 22.05kHz 采样率
- `"volume": 50` —— 音量 50（范围 0-100）
- `"rate": 1.25` —— 语速 1.25 倍。比正常语速稍快
- `"pitch": 1` —— 音调不变

WebSocket 流程和 ASR 完全一致：run-task → 等 task-started → gather(sender, receiver)。

### 4.6 `work()`——线程入口

```python
    def work(self, app, inputs, mq):
        try:
            asyncio.run(self.run_tts_tasks(app, inputs, mq))
        finally:
            mq.put_nowait(None)
```

- `asyncio.run(self.run_tts_tasks(app, inputs, mq))` —— 在线程中创建新事件循环，运行异步 TTS 流程。**阻塞直到 `run_tts_tasks` 完成或抛异常**
- `finally: mq.put_nowait(None)` —— **关键**。无论成功还是失败（包括异常），最后都向队列放入 `None`。主线程读到 `None` 后退出循环、发送 `[DONE]`、保存数据库

### 4.7 `event_stream()`——主线程读队列 + SSE 推送

```python
    def event_stream(self, app, inputs, friend, message):
        mq = Queue()
        thread = threading.Thread(target=self.work, args=(app, inputs, mq))
        thread.start()

        full_output = ''
        full_usage = {}
        while True:
            msg = mq.get()
            if not msg:
                break
            if msg.get('content', None):
                full_output += msg['content']
                yield f'data: {json.dumps({"content": msg["content"]}, ensure_ascii=False)}\n\n'
            if msg.get('audio', None):
                yield f'data: {json.dumps({"audio": msg["audio"]}, ensure_ascii=False)}\n\n'
            if msg.get('usage', None):
                full_usage = msg['usage']

        yield 'data: [DONE]\n\n'
        input_tokens = full_usage.get('input_tokens', 0)
        output_tokens = full_usage.get('output_tokens', 0)
        total_tokens = full_usage.get('total_tokens', 0)
        Message.objects.create(
            friend=friend,
            user_message=message[:500],
            input=json.dumps(
                [m.model_dump() for m in inputs['messages']],
                ensure_ascii=False,
            )[:10000],
            output=full_output[:500],
            input_tokens=input_tokens,
            output_tokens=output_tokens,
            total_tokens=total_tokens,
        )
        if Message.objects.filter(friend=friend).count() % 1 == 0:
            update_memory(friend)
```

**逐行讲解**：

- `mq = Queue()` —— 创建线程安全队列。`queue.Queue` 自带互斥锁，多线程写入/单线程读取不会出现竞态条件
- `threading.Thread(target=self.work, args=(app, inputs, mq))` —— 创建工作线程。`target` 是函数，`args` 是传给函数的参数元组
- `thread.start()` —— 启动线程。线程开始执行 `self.work(app, inputs, mq)`
- `while True: msg = mq.get()` —— 主线程**阻塞等待**。`mq.get()` 从队列取一条消息，如果队列为空则阻塞直到有新消息（或 `None` 信号）
- `if not msg: break` —— `None` 是结束信号，退出循环
- `msg.get('content', None)` → yield SSE 文字事件
- `msg.get('audio', None)` → yield SSE 音频事件（Base64 字符串）
- `msg.get('usage', None)` → 记录 token 统计
- 退出循环后：发送 `[DONE]` + 存数据库 + 更新长期记忆

## 六、总结

| 新增方法 | 运行线程 | 职责 |
|---------|---------|------|
| `tts_sender` | Worker (asyncio) | AI 生成文字 → 发给 TTS → 文字放入队列 |
| `tts_receiver` | Worker (asyncio) | 从 TTS 收 MP3 → Base64 编码 → 放入队列 |
| `run_tts_tasks` | Worker (asyncio) | WebSocket 连接 + 编排 sender/receiver |
| `work` | Worker (thread) | `asyncio.run()` 入口 + `finally` 发送 None |
| `event_stream` | Main | 读队列 → SSE yield → 存数据库 |

**关键设计决策**：用多线程而不是全部异步。因为 Django `StreamingHttpResponse` 要求生成器是同步的（不能在 `async def` 中 `yield`），而 TTS 需要 WebSocket（异步）。解决方案：异步线程跑 WebSocket → 消息队列 → 主线程同步读队列 → yield。
