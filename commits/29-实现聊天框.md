**流程**：点击角色卡片 → `openChatField()` → 
1. 检查登录状态（未登录跳登录页）
2. 调用 `get_or_create` API 创建/获取好友关系
3. 把返回的 `friend` 对象传给 `ChatField` 子组件
4. 调用子组件的 `showModal()` 方法打开对话框

**在模板中**：`@click="openChatField"` 添加在角色卡片的背景图 div 上。

## 三、`ChatField.vue`——对话框 Modal

```vue
<script setup>
const props = defineProps(['friend'])
const modalRef = useTemplateRef('modal-ref')

function showModal() {
  modalRef.value.showModal()           // DaisyUI Modal 的原生方法
}

const modalStyle = computed(() => {
  if (props.friend) {
    return {
      backgroundImage: `url(${props.friend.character.background_image})`,
      backgroundSize: 'cover',
      backgroundPosition: 'center',
      backgroundRepeat: 'no-repeat',
    }
  }
  return {}
})

defineExpose({ showModal })            // 暴露给父组件调用
</script>
```

**动态背景**：`computed(() => {...})` 返回一个 style 对象。当 `friend` 从 `null` 变成有值时，`modalStyle` 自动更新，对话框背景自动换成该角色的聊天背景图。

**`:style="modalStyle"`** —— Vue 的动态样式绑定。`:style` 接受一个对象，`backgroundImage: url(...)` 等价于 CSS 的 `background-image: url(...)`。
