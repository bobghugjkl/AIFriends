## 一、这次提交做了什么

实现了聊天对话框的 UI 框架。点击角色卡片 → 自动创建/获取好友关系 → 弹出一个 DaisyUI Modal（对话框），以角色背景图为底，顶部显示角色头像和名字，底部有输入框和发送/麦克风按钮。**目前只有 UI，还没有真正的发消息逻辑。**

---

## 二、使用了什么技术

| 技术/工具 | 用途 |
|-----------|------|
| DaisyUI Modal | 基于原生 `<dialog>` 的模态框，通过 `showModal()` / `close()` 控制 |
| Vue `computed` | 动态计算对话框背景样式（角色背景图） |
| `useTemplateRef` + `defineExpose` | 父组件通过 ref 调用子组件的 `showModal()` 方法 |
| `@click.stop` | 阻止事件冒泡，防止点击编辑/删除时误触打开聊天框 |
| Tailwind `backdrop-blur-sm` | 输入框的毛玻璃半透明效果 |

## 四、新增文件：`ChatField.vue` —— 对话框 Modal

**路径**：`frontend/src/components/character/chat_field/ChatField.vue`

**完整源码（43 行）：**

```vue
<script setup>
import {computed, useTemplateRef} from "vue";
import InputField from "@/components/character/chat_field/input_field/InputField.vue";
import CharacterPhotoField from "@/components/character/chat_field/character_photo_field/CharacterPhotoField.vue";

const props = defineProps(['friend'])
const modalRef = useTemplateRef('modal-ref')

function showModal() {
  modalRef.value.showModal()
}

const modalStyle = computed(() => {
  if (props.friend) {
    return {
      backgroundImage: `url(${props.friend.character.background_image})`,
      backgroundSize: 'cover',
      backgroundPosition: 'center',
      backgroundRepeat: 'no-repeat',
    }
  } else {
    return {}
  }
})

defineExpose({ showModal })
</script>

<template>
  <dialog ref="modal-ref" class="modal">
    <div class="modal-box w-90 h-150" :style="modalStyle">
      <button @click="modalRef.close()" class="btn btn-sm btn-circle btn-ghost bg-transparent absolute right-1 top-1">✕</button>
      <CharacterPhotoField v-if="friend" :character="friend.character" />
      <InputField v-if="friend" :friendId="friend.id" />
    </div>
  </dialog>
</template>

<style scoped>

</style>
```

**讲解：**
- `useTemplateRef('modal-ref')` —— 获取 `<dialog>` 元素的引用
- `showModal()` —— 调用 DaisyUI Modal 的原生 `showModal()` 方法打开对话框
- `modalStyle` —— `computed` 动态计算背景图样式。当 `friend` 从 `null` 变成有值时，自动更新背景为角色的聊天背景图
- `defineExpose({ showModal })` —— 暴露 `showModal` 方法给父组件 `Character.vue` 调用
- `:style="modalStyle"` —— Vue 的动态样式绑定，`backgroundImage: url(...)` 等价于 CSS 的 `background-image: url(...)`
