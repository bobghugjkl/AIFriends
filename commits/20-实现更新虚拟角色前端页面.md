## 二、`UpdateCharacter.vue`——核心逻辑

```javascript
const route = useRoute()
const characterId = route.params.character_id
const character = ref(null)

onMounted(async () => {
  const res = await api.get('/api/create/character/get_single/', {
    params: {
      character_id: characterId,
    }
  })
  const data = res.data
  if (data.result === 'success') {
    character.value = data.character
  }
})
```

**逐行讲解**：

- `route.params.character_id` —— 从动态路由 `/create/character/update/:character_id/` 中获取 ID
- `character = ref(null)` —— 保存从后端加载的角色数据。初始值为 `null`，用于 template 中的 `v-if`
- `onMounted(async () => {...})` —— 页面挂载后从后端加载角色数据
- `api.get('/api/create/character/get_single/', {params: {character_id: characterId}})` —— GET 请求的查询参数通过 `{params: {...}}` 传入。Axios 自动把它序列化为 `?character_id=xxx` 拼到 URL 后面
- `catch (err) {}` —— 静默处理错误。角色不存在的异常也应该静默（可能用户手动改 URL）
- `character.value = data.character` —— 加载完成后，子组件的 props 同步更新

**更新提交逻辑**：

```javascript
async function handleUpdate() {
  const formData = new FormData()
  formData.append('character_id', characterId)   // 更新必须传 ID
  formData.append('name', name)
  formData.append('profile', profile)

  // 只上传修改过的图（和编辑资料一样的优化）
  if (photo !== character.value.photo) {
    formData.append('photo', base64ToFile(photo, 'photo.png'))
  }
  if (backgroundImage !== character.value.background_image) {
    formData.append('background_image', base64ToFile(backgroundImage, 'background_image.png'))
  }
}
```

**`v-if` 控制渲染时机**：

```html
<div v-if="character" class="flex justify-center">
  <!-- 表单内容 -->
  <Photo ref="photo-ref" :photo="character.photo" />
  <Name ref="name-ref" :name="character.name" />
  ...
</div>
```

数据加载完成前不渲染表单（避免 props 为空传到子组件）。子组件通过 `watch` 监听 props 变化，`character` 从 `null` 变成对象后自动更新内部 `myPhoto`、`myName` 等值。

## 三、路由注册

```javascript
{
  path: '/create/character/update/:character_id/',
  component: UpdateCharacter,
  name: 'update-character',
  meta: { needLogin: true },
}
```

动态参数 `:character_id`，访问 `/create/character/update/5/` 就编辑 id=5 的角色。

## 四、总结

| 操作 | URL | 组件 |
|------|-----|------|
| 创建角色 | `/create/` | `CreateCharacter.vue` |
| 编辑角色 | `/create/character/update/:id/` | `UpdateCharacter.vue` |

更新和创建的**表单结构完全一样**，只是初始数据来源不同——创建是空的，更新是从 API 加载。子组件（Photo、Name、Profile、BackgroundImage）完全复用，只通过 props 区分是"空初始值"还是"已有数据"。
