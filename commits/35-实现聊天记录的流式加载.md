发给 AI 的完整输入（系统提示词+历史消息+当前消息）很容易超过 500 字。

### 2.2 消息持久化

```python
full_output = ''
for msg, metadata in app.stream(inputs, ...):
    if msg.content:
        full_output += msg.content    # 累积完整回复
        yield f'data: ...'
yield 'data: [DONE]\n\n'

# AI回复完 → 保存到数据库
Message.objects.create(
    friend=friend,
    user_message=message[:500],
    input=json.dumps([m.model_dump() for m in inputs['messages']], ensure_ascii=False)[:10000],
    output=full_output[:500],
    input_tokens=input_tokens,
    output_tokens=output_tokens,
    total_tokens=total_tokens,
)
```

### 2.3 `GetHistoryView`——加载历史消息

```python
last_message_id = int(request.query_params.get('last_message_id'))
queryset = Message.objects.filter(friend_id=friend_id, friend__me__user=request.user)
if last_message_id > 0:
    queryset = queryset.filter(pk__lt=last_message_id)  # 游标分页
messages_raw = queryset.order_by('-id')[:10]
```

**游标分页（Cursor Pagination）**：用已加载消息中最小 id 作为"游标"，查询 id 小于该游标的消息。比 offset 分页更适合实时追加的数据——新消息插入不会导致翻页重复。

## 三、前端：消息组件体系

```
ChatField.vue           ← 对话框容器，管理 history 数组
├── ChatHistory.vue     ← 消息列表区域（滚动）+ 历史加载
│   └── Message.vue     ← 单条消息气泡（AI靠左/用户靠右）
├── InputField.vue      ← 输入框 + 发送
└── CharacterPhotoField.vue  ← 顶部角色信息条
```

### `Message.vue`——消息气泡

```html
<div v-if="message.role === 'ai'" class="chat chat-start">
  <div class="chat-image avatar">
    <div class="w-10 rounded-full">
      <img :src="character.photo" alt="">
    </div>
  </div>
  <div class="chat-bubble whitespace-pre-wrap">{{ message.content }}</div>
</div>
<div v-else class="chat chat-end">
  <div class="chat-image avatar">
    <img :src="user.photo" alt="">
  </div>
  <div class="chat-bubble chat-bubble-success whitespace-pre-wrap">{{ message.content }}</div>
</div>
```

- `chat-start` / `chat-end` —— DaisyUI 的聊天气泡组件。start=靠左（AI），end=靠右（用户）
- `chat-bubble-success` —— 用户气泡绿色背景，AI 气泡默认灰色
- `whitespace-pre-wrap` —— 保留换行符和空格，AI 回复中的换行能正常显示

### `InputField.vue`——发送即时展示

```javascript
// 先push用户消息+空的AI占位
emit('pushBackMessage', {role: 'user', content: content, id: crypto.randomUUID()})
emit('pushBackMessage', {role: 'ai', content: '', id: crypto.randomUUID()})

// 流式返回时添加到占位AI消息

  emit('addToLastMessage', data.content)  // 逐字追加
```
