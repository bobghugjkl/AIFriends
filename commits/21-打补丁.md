## 二、完整源代码

### 2.1 修复删除角色时不删文件的 bug

**文件**：`backend/web/views/create/character/remove.py`

**改之前**（第17/18次提交后的代码）：

```python
from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework.permissions import IsAuthenticated

from web.models.character import Character


class RemoveCharacterView(APIView):
    permission_classes = [IsAuthenticated]
    def post(self, request):
        try:
            character_id = request.data['character_id']
            Character.objects.filter(pk=character_id, author__user=request.user).delete()
            return Response({
                'result': 'success',
            })
        except:
            return Response({
                'result': '系统异常，请稍后重试'
            })
```

**改之后**（本次提交后的完整内容）：

```python
from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework.permissions import IsAuthenticated

from web.models.character import Character
from web.views.utils.photo import remove_old_photo


class RemoveCharacterView(APIView):
    permission_classes = [IsAuthenticated]
    def post(self, request):
        try:
            character_id = request.data['character_id']
            character = Character.objects.get(pk=character_id, author__user=request.user)
            remove_old_photo(character.photo)
            remove_old_photo(character.background_image)
            character.delete()
            return Response({
                'result': 'success',
            })
        except:
            return Response({
                'result': '系统异常，请稍后重试'
            })
```

**问题**：之前用 `.filter().delete()` 直接删数据库记录，但**角色头像和背景图文件还留在磁盘上**。长期运行后 `media/character/photos/` 和 `media/character/background_images/` 会堆满废弃文件。

**改进**：先取到对象 → 用 `remove_old_photo` 删两个图片文件 → 再 `character.delete()` 删数据库记录。`.get()` 找不到角色会抛异常，进入 `except` 返回"系统异常"，逻辑更严谨。
