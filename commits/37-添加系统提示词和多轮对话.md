## 一、这次提交做了什么

让 AI **真正知道自己的角色**并能**记住对话历史**。通过两个新函数把系统提示词和历史消息插入聊天请求中，彻底改变了 AI 对话质量——从"无记忆的通用助手"变成"有人设、能记住前文的专属 AI 朋友"。

## 二、使用了什么技术

| 技术 | 用途 |
|------|------|
| LangChain `SystemMessage` | 系统指令消息类型，AI 最高优先级行为准则 |
| LangChain `HumanMessage` | 用户消息类型 |
| LangChain `AIMessage` | AI 回复消息类型 |
| Django QuerySet `order_by` + slicing | 按时间排序并取最近 N 条记录 |
| Python list slicing | 消息列表拼接：`msgs[:1] + messages + msgs[-1:]` |

## 三、整体架构 / 数据流

```
Message composition (消息组装流程):

   User sends message
          │
          ▼
   inputs = {'messages': [HumanMessage(message)]}
          │
     ┌─────┴─────┐
     │   ①       │
     │ add_system_prompt(inputs, friend)
     │           │
     │  SELECT * FROM SystemPrompt WHERE title='回复'
     │  ORDER BY order_number
     │           │
     │  prompt = concatenated rules + character.profile
     │           │
     │  msgs = [SystemMessage(prompt)] + original_msgs
     │           │
     └─────┬─────┘
           │
     ┌─────┴─────┐
     │   ②       │
     │ add_recent_messages(inputs, friend)
     │           │
     │  SELECT * FROM Message WHERE friend=friend
     │  ORDER BY -id LIMIT 10
     │           │
     │  messages = [HumanMsg, AIMsg, HumanMsg, AIMsg, ...]
     │           │
     │  msgs = msgs[:1] + messages + msgs[-1:]
     │  (system)   (history)   (current user msg)
     │           │
     └─────┬─────┘
           │
           ▼
   Final message list sent to AI:
   [SystemMsg, Human1, AI1, Human2, AI2, ..., Human10, AI10, CurrentUserMsg]
```

## 四、新增 SystemPrompt 模型

**文件**：`backend/web/models/friend.py`

```python
class SystemPrompt(models.Model):
    title = models.CharField(max_length=100)
    order_number = models.IntegerField(default=0)
    prompt = models.TextField(max_length=10000)
    create_time = models.DateTimeField(default=now)
    update_time = models.DateTimeField(default=now)
```

- `title` —— 提示词分类。`'回复'` 用于聊天行为指导，`'记忆'` 用于长期记忆提取（后面会用到）
- `order_number` —— 排序。数字越小越靠前，多条规则按序号拼接
- `prompt` —— 提示词正文（最长1万字）。相比 `profile`（角色性格存档），`SystemPrompt` 是**行为规则**，如"回复要简洁"、"不要说自己是AI"
- 这是**全局配置表**，不关联任何用户或角色，所有聊天共用

## 五、`add_system_prompt`——注入系统提示词

```python
def add_system_prompt(state, friend):
    msgs = state['messages']
    system_prompts = SystemPrompt.objects.filter(title='回复').order_by('order_number')
    prompt = ''
    for sp in system_prompts:
        prompt += sp.prompt
    prompt += f'\n【角色性格】\n{friend.character.profile}\n'
    return {'messages': [SystemMessage(prompt)] + msgs}
```

1. 查出所有 `title=回复` 的系统提示词，按序号拼接
2. 附加上角色性格（`friend.character.profile`）
3. 包成 `SystemMessage` 插到消息列表**最前面**

`SystemMessage` 是 LangChain 的"系统指令"类型，AI 会把它当作最高优先级行为准则，但聊天界面**不显示**。

## 六、`add_recent_messages`——注入历史对话

```python
def add_recent_messages(state, friend):
    msgs = state['messages']
    message_raw = list(Message.objects.filter(friend=friend).order_by('-id')[:10])
    message_raw.reverse()                                            # 倒序→正序
    messages = []
    for m in message_raw:
        messages.append(HumanMessage(m.user_message))
        messages.append(AIMessage(m.output))
    return {'messages': msgs[:1] + messages + msgs[-1:]}
```

**精妙的切片拼接**：
- `msgs[:1]` —— 第一条 = 系统提示词
- `messages` —— 中间插入 10 轮历史
- `msgs[-1:]` —— 最后一条 = 用户当前消息

最终发给 AI 的消息列表：
```
[System提示词, 用户1, AI1, 用户2, AI2, ..., 用户10, AI10, 当前用户消息]
```

**为什么用切片而不用直接索引**：`msgs[-1:]` 返回单个元素的列表，可以直接 `+` 拼接。如果用 `msgs[-1]` 返回的是单个元素，不能和列表相加。

## 七、MessageChatView 调用顺序

```python
inputs = {'messages': [HumanMessage(message)]}
inputs = add_system_prompt(inputs, friend)    # 先：加系统提示词
inputs = add_recent_messages(inputs, friend)  # 后：加历史消息
```

**顺序有讲究**：`add_recent_messages` 的 `msgs[:1]` 依赖第一条是系统提示词。如果先加历史再加系统提示词，切片逻辑就乱了。
