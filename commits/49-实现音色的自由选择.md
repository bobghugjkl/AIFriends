## 二、源码

### 2.1 Voice 模型

**文件**：`backend/web/models/character.py`

```python
class Voice(models.Model):
    name = models.CharField(max_length=100)
    voice_id = models.CharField(max_length=100)
    create_time = models.DateTimeField(default=now)

    def __str__(self):
        return f"{self.name} - {self.voice_id} - {localtime(self.create_time).strftime('%Y-%m-%d %H:%M:%S')}"
```

- `name` —— 显示名（如"龙羊羊"、"温柔女声"）
- `voice_id` —— API 中的音色标识符（如 `"longanyang"`），传给 TTS 的 `voice` 参数
- `create_time` —— 创建时间

**Voice 是管理员在 Django Admin 后台手动添加的预设表**，用户不能自己创建音色（后续提交 #51 增加了语音复刻功能允许用户创建定制音色）。

**Character 新增外键**：

```python
class Character(models.Model):
    ...
+   voice = models.ForeignKey(Voice, default=None, on_delete=models.CASCADE, blank=True, null=True)
```

- `blank=True, null=True` —— 允许为空。旧的 Character 记录在迁移前没有 voice，设为 null 兼容
- `default=None` —— 默认无音色

### 2.2 `Voice.vue`——音色下拉选择组件（新文件，31行）

```vue
<script setup>
import {ref, watch} from "vue";

const props = defineProps(['voices', 'curVoiceId'])
const myVoice = ref(props.curVoiceId)

watch(() => props.curVoiceId, newVal => {
  myVoice.value = newVal
})

defineExpose({
  myVoice,
})
</script>

<template>
  <fieldset class="fieldset">
    <label class="label text-base">音色</label>
    <select v-model="myVoice" class="select">
      <option
          v-for="voice in voices"
          :id="voice.id"
          :value="voice.id"
      >{{ voice.name }}</option>
    </select>
  </fieldset>
</template>
```

**逐行讲解**：

- `defineProps(['voices', 'curVoiceId'])` —— `voices` 是可选音色数组 `[{id, name}, ...]`；`curVoiceId` 是当前选中的音色 ID
- `const myVoice = ref(props.curVoiceId)` —— 初始化为当前音色 ID
- `watch(() => props.curVoiceId, newVal => { myVoice.value = newVal })` —— 监听 props 变化。编辑角色时 API 返回的 `voice_id` 可能异步到达，watch 保证下拉框自动更新
- `defineExpose({ myVoice })` —— 暴露给父组件，模式和之前的 Name/Profile/Photo 组件完全一致
- `<select v-model="myVoice" class="select">` —— DaisyUI 下拉选择框，`v-model` 双向绑定选中的 `voice.id`
- `v-for="voice in voices" :value="voice.id"` —— 遍历可选音色列表，每个 option 的 value 是音色 ID

### 2.3 `get_list.py`——音色列表 API（新文件，26行）

```python
from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework.permissions import IsAuthenticated
from web.models.character import Voice


class GetVoiceList(APIView):
    permission_classes = [IsAuthenticated]
    def get(self, request):
        try:
            voices_raw = Voice.objects.order_by('id')
            voices = []
            for v in voices_raw:
                voices.append({
                    'id': v.id,
                    'name': v.name,
                })
            return Response({
                'result': 'success',
                'voices': voices,
            })
        except:
            return Response({
                'result': '系统异常，请稍后重试'
            })
```

返回全部音色列表（按 id 排序），每条只返回 `id` 和 `name`（不需要 `voice_id` 暴露给前端）。路由：`/api/create/character/voice/get_list/`。
