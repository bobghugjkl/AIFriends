## 一、这次提交做了什么

让用户创建/编辑角色时**可以选择 TTS 音色**（AI 说话的声音）。之前 `cosyvoice-v3-flash` 的 voice 参数是写死的 `"longanyang"`，现在每个角色可以有自己的音色。

---

## 二、Voice 模型

**文件**：`backend/web/models/character.py`

```python
class Voice(models.Model):
    name = models.CharField(max_length=100)        # 显示名（如"龙羊羊"）
    voice_id = models.CharField(max_length=100)    # API中的音色ID
    create_time = models.DateTimeField(default=now)
```

`Voice` 是管理员在后台手动添加的**预设音色表**。用户创建角色时从已有音色中选择。

**Character 新增外键**：

```python
voice = models.ForeignKey(Voice, default=None, on_delete=models.CASCADE, blank=True, null=True)
```

## 三、后端改动

### 创建/更新角色时传 `voice_id`

```python
voice_id = request.data.get('voice_id')
voice = Voice.objects.get(id=voice_id)
Character.objects.create(..., voice=voice, ...)
```

### 获取角色时返回音色列表

`GetSingleCharacterView` 现在返回：
```python
'voices': [{'id': v.id, 'name': v.name}, ...]  # 可选音色列表
'voice_id': character.voice.id                  # 当前角色音色ID
```

### TTS API 动态传音色

```python
# chat.py
async def run_tts_tasks(self, app, inputs, mq, voice_id):
    "voice": voice_id,   # 不再写死"longanyang"

# event_stream中
thread = threading.Thread(target=self.work, 
    args=(app, inputs, mq, friend.character.voice.voice_id))
#                            ↑ 取角色绑定的音色ID
```

### `GetVoiceList`——音色列表 API

```python
# /api/create/character/voice/get_list/
voices_raw = Voice.objects.order_by('id')
```

## 四、前端：音色选择下拉框

**`Voice.vue`**（新组件）：

```html
<select v-model="myVoice" class="select">
  <option v-for="voice in voices" :value="voice.id">
    {{ voice.name }}
  </option>
</select>
```

创建/更新角色页面各加了一个 `<Voice>` 子组件，`defineExpose({myVoice})` 暴露给父组件。

## 五、总结

| 改动 | 说明 |
|------|------|
| `Voice` 模型 | 管理员预设的音色表（name + voice_id） |
| `Character.voice` 外键 | 角色绑定一个音色 |
| `GetVoiceList` API | 返回可选音色列表 |
| TTS voice 参数动态化 | 用角色的音色ID替代写死值 |
| `Voice.vue` | 前端下拉框选择音色 |
