## 一、这次提交做了什么

创建了 **Friend 模型**——表示"用户和 AI 角色的好友关系"。这是聊天的前提：用户必须先和某个角色"成为好友"，然后才能聊天。提供了三个 API：添加好友（或获取已有好友关系）、获取好友列表、删除好友。

---

## 二、使用了什么技术

| 技术/工具 | 用途 |
|-----------|------|
| Django `ForeignKey` | `Friend.me` → `UserProfile`，`Friend.character` → `Character` |
| `.filter().exists()` + `.first()` | 先检查记录是否存在，再获取第一条 |
| `get_or_create` 模式 | 幂等设计：已存在则返回，不存在则创建 |
| `.order_by('-update_time')` | 按最近更新时间排序，最近聊天的好友排最前 |

### 3.1 `models/friend.py`——Friend 模型

**文件**：`backend/web/models/friend.py`（新文件，完整内容）

```python
from django.db import models
from django.utils.timezone import now, localtime

from web.models.character import Character
from web.models.user import UserProfile


class Friend(models.Model):
    me = models.ForeignKey(UserProfile, on_delete=models.CASCADE)
    character = models.ForeignKey(Character, on_delete=models.CASCADE)
    memory = models.TextField(default="", max_length=5000, blank=True, null=True)
    create_time = models.DateTimeField(default=now)
    update_time = models.DateTimeField(default=now)

    def __str__(self):
        return f"{self.character.name} - {self.me.user.username} - {localtime(self.create_time).strftime('%Y-%m-%d %H:%M:%S')}"
```

**逐字段讲解**：

- `me` —— **当前用户**的 UserProfile。外键指向 UserProfile，"我"和谁成了好友
- `character` —— **AI 角色**的外键。"我"加了哪个角色为好友
- `memory` —— **长期记忆**字段。后面的提交会用到——AI 可以记住和用户的对话要点，存在这个字段里。最长 5000 字。`blank=True, null=True` 表示可为空（刚加好友时还没记忆）
- 组合不是唯一约束——用户可以分别和同一个角色的多个"版本"成为好友（不过业务逻辑限制了一个用户对一个角色只有一个好友关系，通过 `get_or_create` 保证）

### 3.2 `views/friend/get_or_create.py`——添加好友

**文件**：`backend/web/views/friend/get_or_create.py`（新文件，完整内容）

```python
from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework.permissions import IsAuthenticated

from web.models.friend import Friend
from web.models.user import UserProfile


class GetOrCreateFriendView(APIView):
    permission_classes = [IsAuthenticated]
    def post(self, request):
        try:
            character_id = request.data['character_id']
            user = request.user
            user_profile = UserProfile.objects.get(user=user)
            friends = Friend.objects.filter(character_id=character_id, me=user_profile)
            if friends.exists():
                friend = friends.first()
            else:
                friend = Friend.objects.create(character_id=character_id, me=user_profile)
            character = friend.character
            author = character.author
            return Response({
                'result': 'success',
                'friend': {
                    'id': friend.id,
                    'character': {
                        'id': character.id,
                        'name': character.name,
                        'profile': character.profile,
                        'photo': character.photo.url,
                        'background_image': character.background_image.url,
                        'author': {
                            'user_id': author.user_id,
                            'username': author.user.username,
                            'photo': author.photo.url,
                        }
                    }
                }
            })
        except:
            return Response({
                'result': '系统异常，请稍后重试'
            })
```

**命名含义**：`GetOrCreate`——**如果好友关系已存在就直接返回，否则创建新的**。这是"幂等"设计——用户多次点同一个角色的"聊天"按钮，不会创建重复的好友关系。

### 3.3 `views/friend/get_list.py`——好友列表

**文件**：`backend/web/views/friend/get_list.py`（新文件，完整内容）

```python
from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework.permissions import IsAuthenticated

from web.models.friend import Friend


class GetListFriendView(APIView):
    permission_classes = [IsAuthenticated]
    def get(self, request):
        try:
            items_count = int(request.query_params.get('items_count', 0))
            friends_raw = Friend.objects.filter(
                me__user=request.user
            ).order_by('-update_time')[items_count: items_count + 20]
            friends = []
            for friend in friends_raw:
                character = friend.character
                author = character.author
                friends.append({
                    'id': friend.id,
                    'character': {
                        'id': character.id,
                        'name': character.name,
                        'profile': character.profile,
                        'photo': character.photo.url,
                        'background_image': character.background_image.url,
                        'author': {
                            'user_id': author.user_id,
                            'username': author.user.username,
                            'photo': author.photo.url,
                        }
                    }
                })
            return Response({
                'result': 'success',
                'friends': friends,
            })
        except:
            return Response({
                'result': '系统异常，请稍后重试'
            })
```

- `me__user=request.user` —— 通过两重外键过滤：`Friend.me` → `UserProfile.user` → `request.user`
- `.order_by('-update_time')` —— 按**最近联系时间**排序，最近聊天过的好友排最前面
- 分页机制和角色列表一样，每次 20 条

### 3.4 `views/friend/remove.py`——删除好友

**文件**：`backend/web/views/friend/remove.py`（新文件，完整内容）

```python
from rest_framework.response import Response
from rest_framework.views import APIView
from rest_framework.permissions import IsAuthenticated

from web.models.friend import Friend


class RemoveFriendView(APIView):
    permission_classes = [IsAuthenticated]
    def post(self, request):
        try:
            friend_id = request.data['friend_id']
            Friend.objects.filter(id=friend_id, me__user=request.user).delete()
            return Response({
                'result': 'success',
            })
        except:
            return Response({
                'result': '系统异常，请稍后重试'
            })
```

只有该好友关系的主人（`me`）能删除。其他人删不了。

## 四、总结

| API | URL | 功能 |
|------|-----|------|
| `GetOrCreateFriendView` | `POST /api/friend/get_or_create/` | 添加好友（幂等，不重复创建） |
| `GetListFriendView` | `GET /api/friend/get_list/` | 获取好友列表（按最近联系排序） |
| `RemoveFriendView` | `POST /api/friend/remove/` | 删除好友 |

| 模型 | 含义 |
|------|------|
| `Friend.me` | 谁的好友 |
| `Friend.character` | 哪个 AI 角色 |
| `Friend.memory` | 长期记忆（5000字，暂未使用） |
