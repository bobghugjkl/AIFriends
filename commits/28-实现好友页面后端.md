## 一、这次提交做了什么

创建了 **Friend 模型**——表示"用户和 AI 角色的好友关系"。这是聊天的前提：用户必须先和某个角色"成为好友"，然后才能聊天。提供了三个 API：添加好友（或获取已有好友关系）、获取好友列表、删除好友。

## 二、Friend 模型

**文件**：`backend/web/models/friend.py`（新文件）

```python
class Friend(models.Model):
    me = models.ForeignKey(UserProfile, on_delete=models.CASCADE)
    character = models.ForeignKey(Character, on_delete=models.CASCADE)
    memory = models.TextField(default="", max_length=5000, blank=True, null=True)
    create_time = models.DateTimeField(default=now)
    update_time = models.DateTimeField(default=now)
```

**逐字段讲解**：

- `me` —— **当前用户**的 UserProfile。外键指向 UserProfile，"我"和谁成了好友
- `character` —— **AI 角色**的外键。"我"加了哪个角色为好友
- `memory` —— **长期记忆**字段。后面的提交会用到——AI 可以记住和用户的对话要点，存在这个字段里。最长 5000 字。`blank=True, null=True` 表示可为空（刚加好友时还没记忆）
- `me` + `character` 的组合**不是唯一的**——用户可以分别和同一个角色的多个"版本"成为好友（不过这个项目的业务逻辑限制了一个用户对一个角色只有一个好友关系，通过 `get_or_create` 保证）

## 三、GetOrCreateFriendView——添加好友

**文件**：`backend/web/views/friend/get_or_create.py`（新文件）

```python
class GetOrCreateFriendView(APIView):
    permission_classes = [IsAuthenticated]
    def post(self, request):
        character_id = request.data['character_id']
        user_profile = UserProfile.objects.get(user=request.user)
        friends = Friend.objects.filter(character_id=character_id, me=user_profile)
        if friends.exists():
            friend = friends.first()
        else:
            friend = Friend.objects.create(character_id=character_id, me=user_profile)
```

**命名含义**：`GetOrCreate`——**如果好友关系已存在就直接返回，否则创建新的**。这是"幂等"设计——用户多次点同一个角色的"聊天"按钮，不会创建重复的好友关系。`friends.exists()` + `friends.first()` 先检查再取第一条。

## 四、GetListFriendView——好友列表

```python
friends_raw = Friend.objects.filter(
    me__user=request.user
).order_by('-update_time')[items_count: items_count + 20]
```

- `me__user=request.user` —— 通过两重外键过滤：`Friend.me` → `UserProfile.user` → `request.user`
- `.order_by('-update_time')` —— 按**最近联系时间**排序，最近聊天过的好友排最前面
- 分页机制和角色列表一样，每次 20 条

## 五、RemoveFriendView——删除好友

```python
Friend.objects.filter(id=friend_id, me__user=request.user).delete()
```

只有该好友关系的主人（`me`）能删除。其他人删不了。

## 七、总结

| API | URL | 功能 |
|------|-----|------|
| `GetOrCreateFriendView` | `POST /api/friend/get_or_create/` | 添加好友（幂等，不重复创建） |
| `GetListFriendView` | `GET /api/friend/get_list/` | 获取好友列表（按最近联系排序） |
| `RemoveFriendView` | `POST /api/friend/remove/` | 删除好友 |

| 模型 | 含义 |
|------|------|
| `Friend.me` | 谁的好友 |
| `Friend.character` | 哪个 AI 角色 |
| `Friend.memory` | 长期记忆（5000字，暂未使用） |
