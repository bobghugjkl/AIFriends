---

## 二、bug 1：`remove.py` 缺少成功响应

```diff
             Character.objects.filter(pk=character_id, author__user=request.user).delete()
+            return Response({
+                'result': 'success',
+            })
```

**问题**：删除成功后没有返回任何响应，Django 不会报错，但前端收到的响应体为空，无法判断删除是否成功。加上 `return Response({...})` 后前端用 `if (data.result === 'success')` 就能正常处理。

## 三、bug 2：`update.py` 缺少 `return`

```diff
-            Response({
+            return Response({
                 'result': '系统异常，请稍后重试'
             })
```

**问题**：`except` 分支调用了 `Response(...)` 但没有 `return`。Python 函数没有 `return` 语句时默认返回 `None`，导致异常情况下前端收不到响应，请求会一直 hang 直到超时。这是个典型的漏写 `return` 的 bug。"系统异常"本身已经是兜底错误处理，再让请求超时就变成了双重错误。

## 四、总结

| 修复 | 影响 |
|------|------|
| remove 加 return Response | 前端能收到删除成功的确认 |
| update except 加 return | 异常时前端能收到错误信息而不是超时 |
