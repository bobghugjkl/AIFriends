## 二、改动1：导航栏搜索框居中对齐

**文件**：`frontend/src/components/navbar/NavBar.vue`

```diff
-        <div class="navbar-center w-4/5 max-w-180">
-          <div class="join w-4/5">
+        <div class="navbar-center w-4/5 max-w-180 flex justify-center">
+          <div class="join w-4/5 flex justify-center">
```

**逐行讲解**：

- `flex` —— Tailwind 的 `display: flex`。把容器变成弹性盒布局，子元素可以灵活排列
- `justify-center` —— 弹性盒的主轴居中。当 `flex` 方向为默认的横向时，`justify-center` 就是**水平居中**
- 两处都加了 `flex justify-center`：外层 `navbar-center` 加是为了让 join 组在它的区域内居中；内层 join 加是为了让搜索框本身居中。两层居中保证了搜索框在导航栏的视觉中心

**改之前的问题**：`navbar-center` 里的内容靠左对齐，搜索框不在导航栏正中间，看着歪。加了居中后搜索框在视觉正中央，更美观。
