## 四、Croppie Modal 异步 bug 修复

### 4.1 `Photo.vue`（创建角色用）

**文件**：`frontend/src/views/create/character/components/Photo.vue`

**修复前**：

```vue
<script setup>
import {onBeforeUnmount, ref, useTemplateRef, watch} from "vue";
import CameraIcon from "@/views/user/profile/components/icon/CameraIcon.vue";
import Croppie from 'croppie'
import 'croppie/croppie.css'

const props = defineProps(['photo'])
const myPhoto = ref(props.photo)

watch(() => props.photo, newVal => {
  myPhoto.value = newVal
})

const fileInputRef = useTemplateRef('file-input-ref')
const modalRef = useTemplateRef('modal-ref')
const croppieRef = useTemplateRef('croppie-ref')
let croppie = null

async function openModal(photo) {
  modalRef.value.showModal()
  // BUG: 这里缺少 await nextTick()
  // DOM 可能还没渲染完成，Croppie 拿到的尺寸可能不对

  if (!croppie) {
    croppie = new Croppie(croppieRef.value, {
      viewport: {width: 200, height: 200, type: 'square'},
      boundary: {width: 300, height: 300},
      enableOrientation: true,
      enforceBoundary: true,
    })
  }
  // ...
}
```

**修复后**：

```diff
 async function openModal(photo) {
   modalRef.value.showModal()
+  await nextTick()

   if (!croppie) {
     croppie = new Croppie(croppieRef.value, { ... })
   }
```

完整的 import 也要添加 `nextTick`：

```diff
-import {onBeforeUnmount, ref, useTemplateRef, watch} from "vue";
+import {nextTick, onBeforeUnmount, ref, useTemplateRef, watch} from "vue";
```

### 4.2 `BackgroundImage.vue`（创建角色用）

**文件**：`frontend/src/views/create/character/components/BackgroundImage.vue`

同样的修复：

```diff
-import {onBeforeUnmount, ref, useTemplateRef, watch} from "vue";
+import {nextTick, onBeforeUnmount, ref, useTemplateRef, watch} from "vue";
 
 async function openModal(photo) {
   modalRef.value.showModal()
+  await nextTick()
 
   if (!croppie) {
     croppie = new Croppie(croppieRef.value, { ... })
   }
```

**问题**：`showModal()` 打开 DaisyUI Modal 后，Modal 内的 DOM 元素（`croppieRef`）还没渲染到页面上。这时候 `new Croppie(croppieRef.value, ...)` 可能拿到一个还未完成布局的元素，导致 Croppie 尺寸计算错误。

**修复**：`await nextTick()` 等待 Vue 的 DOM 更新周期完成，确保 `croppieRef.value` 对应的 `<div>` 已经渲染并参与文档流，Croppie 能拿到正确的尺寸。编辑资料页的 `Photo.vue` 已经在 `openModal` 里有了 `nextTick`，这是把遗漏的两个组件的同样逻辑补上。
