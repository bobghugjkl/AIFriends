## 一、这次提交做了什么

实现了**长期记忆提取**——每次聊天结束后，用独立 LLM 分析最近对话，提取要点存到 `Friend.memory` 字段。下次聊天注入系统提示词，让 AI 在 10 轮对话限制外记住更早的关键信息。

## 二、源码改动

### 2.1 `memory/graph.py`——记忆提取工作流（新文件，32行）

```python
import os
from typing import TypedDict, Annotated, Sequence

from langchain_core.messages import BaseMessage
from langchain_openai import ChatOpenAI
from langgraph.constants import START, END
from langgraph.graph import add_messages, StateGraph


class MemoryGraph:
    @staticmethod
    def create_app():
        llm = ChatOpenAI(
            model='deepseek-v3.2',
            openai_api_key=os.getenv('API_KEY'),
            openai_api_base=os.getenv('API_BASE'),
        )

        class AgentState(TypedDict):
            messages: Annotated[Sequence[BaseMessage], add_messages]

        def model_call(state: AgentState) -> AgentState:
            res = llm.invoke(state['messages'])
            return {'messages': [res]}

        graph = StateGraph(AgentState)
        graph.add_node('agent', model_call)

        graph.add_edge(START, 'agent')
        graph.add_edge('agent', END)

        return graph.compile()
```

结构和 `ChatGraph` 相同（START→agent→END），区别在输入——MemoryGraph 输入是"规则+旧记忆+最近对话"，输出是更新后的记忆摘要。

### 2.2 `memory/update.py`——记忆更新逻辑（新文件，45行）

```python
from pprint import pprint

from django.utils.timezone import now
from langchain_core.messages import SystemMessage, HumanMessage

from web.models.friend import SystemPrompt, Message
from web.views.friend.message.memory.graph import MemoryGraph


def create_system_message():
    system_prompts = SystemPrompt.objects.filter(title='记忆').order_by('order_number')
    prompt = ''
    for sp in system_prompts:
        prompt += sp.prompt
    return SystemMessage(prompt)


def create_human_message(friend):
    prompt = f'【原始记忆】\n{friend.memory}\n'
    prompt += f'【最近对话】\n'
    messages = list(Message.objects.filter(friend=friend).order_by('-id')[:10])
    messages.reverse()
    for m in messages:
        prompt += f'user: {m.user_message}\n'
        prompt += f'ai: {m.output}\n'
    return HumanMessage(prompt)


def update_memory(friend):
    app = MemoryGraph.create_app()

    inputs = {
        'messages': [
            create_system_message(),
            create_human_message(friend),
        ]
    }

    pprint(inputs)
    res = app.invoke(inputs)
    friend.memory = res['messages'][-1].content
    pprint(friend.memory)

    friend.update_time = now()
    friend.save()
```

**逐函数讲解**：

**`create_system_message()`**：
- `SystemPrompt.objects.filter(title='记忆')` —— 查 title 为"记忆"的系统提示词。管理员后台写规则如"从对话中提取用户偏好、约定、重要事实，用简洁中文总结"
- `.order_by('order_number')` → 拼接多条规则 → 包成 `SystemMessage`

**`create_human_message(friend)`**：
- `prompt = f'【原始记忆】\n{friend.memory}\n'` —— 当前旧记忆。首次聊天为空字符串
- `prompt += f'【最近对话】\n'` —— 追加最近 10 条消息
- `Message.objects.filter(friend=friend).order_by('-id')[:10]` —— 取最新 10 条
- `messages.reverse()` —— 倒序→正序（最旧到最新）
- 拼接为 `user: ...\nai: ...\n` 对话格式 → 包成 `HumanMessage`

**`update_memory(friend)`**：
- `MemoryGraph.create_app()` → `app.invoke(inputs)` → AI 输出摘要
- `friend.memory = res['messages'][-1].content` —— AI 输出直接存入 `friend.memory`
- `friend.update_time = now()` → `friend.save()` —— 持久化
- `pprint` 是调试代码，后续提交删除

## 三、记忆循环

```
聊天 → 消息入库 → update_memory()
→ MemoryGraph.invoke({System(记忆规则), Human(旧记忆+新对话)})
→ AI 输出摘要 → friend.memory = 摘要
→ 下次聊天 add_system_prompt 注入 【长期记忆】
```
