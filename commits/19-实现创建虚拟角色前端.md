## 三、`CreateCharacter.vue`——创建角色表单主组件

```javascript
const photoRef = useTemplateRef('photo-ref')
const nameRef = useTemplateRef('name-ref')
const profileRef = useTemplateRef('profile-ref')
const backgroundImageRef = useTemplateRef('background-image-ref')
```

4 个子组件都通过 ref 引用，提交时统一读取数据。

**提交逻辑和编辑资料几乎一样**，区别在于：
- 调用的 API 是 `/api/create/character/create/`
- **4 个字段全为必填**（编辑资料头像可选，创建角色必须传）
- 创建成功后跳转到个人空间（`user-space-index`）
- 头像和背景图**无条件上传**（因为创建时一定有图，不像编辑资料可以跳过）

**`nameRef.value.myName?.trim()`** —— `?.` 可选链。子组件可能还没挂载（组件 ref 初始值为 null）就调了 `handleCreate`，加上 `?.` 防止空指针异常。

## 四、4 个子组件

### `Photo.vue`——角色头像
和编辑资料的 `Photo.vue` 功能完全相同（Croppie 裁剪 → Base64 输出），唯一区别是当 `myPhoto` 为空时显示灰色圆形占位而不是空 div。

### `Name.vue`——角色名
输入框组件，和编辑资料的 `Username.vue` 一样的模式。

### `Profile.vue`——角色介绍
和编辑资料的 `Profile.vue` 一样的多行文本框。

### `BackgroundImage.vue`——聊天背景图
裁剪器 viewport 是 `{width: 300, height: 500}`（竖长方形），不是正方形。因为聊天背景通常是竖版的手机壁纸比例。显示也使用 `w-15 h-25`（60×100px）的缩略图预览。

**所有 4 个子组件共用一个 Croppie 模式**：点击缩略图 → 触发 `<input type="file">` → FileReader 读为 Base64 → 打开 DaisyUI Modal → Croppie 绑定图片 → 用户裁剪 → 输出 Base64 → 关闭 Modal。
