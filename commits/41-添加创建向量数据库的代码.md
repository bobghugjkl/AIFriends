## 二、`CustomEmbeddings`——自定义 Embedding 类

**文件**：`backend/web/documents/utils/custom_embeddings.py`（新文件）

```python
from langchain_core.embeddings import Embeddings
from openai import OpenAI

class CustomEmbeddings(Embeddings):
    def __init__(self):
        self.client = OpenAI(
            api_key=os.getenv("API_KEY"),
            base_url=os.getenv("API_BASE")
        )

    def embed_documents(self, texts):
        batch_size = 10
        all_embeddings = []
        for i in range(0, len(texts), batch_size):
            batch = texts[i: i + batch_size]
            batch = [t for t in batch if t.strip()]    # 过滤空字符串
            if not batch:
                continue
            response = self.client.embeddings.create(
                model="text-embedding-v4",            # DeepSeek 的 Embedding 模型
                input=batch,
                dimensions=1024                       # 1024维向量
            )
            all_embeddings.extend([data.embedding for data in response.data])
        return all_embeddings

    def embed_query(self, text):
        return self.embed_documents([text])[0]
```

**逐行讲解**：

- `Embeddings` —— LangChain 的抽象基类。继承它并实现两个方法：`embed_documents`（批量向量化）和 `embed_query`（单条查询向量化）
- `batch_size = 10` —— API 一次最多处理 10 条，分批防止超出限额
- `model="text-embedding-v4"` —— DeepSeek 的文本向量化模型
- `dimensions=1024` —— 每个文本被转成 1024 个浮点数（1024 维向量）。维度越高语义表示越精细，但计算和存储成本越高
- `embed_query` 直接调用 `embed_documents([text])[0]` —— 单条查询也用批量方法，取第一个（也是唯一一个）结果

## 三、`insert_documents.py`——灌库脚本

**文件**：`backend/web/documents/utils/insert_documents.py`（新文件）

```python
def insert_documents():
    loader = TextLoader('./web/documents/data.txt', encoding='utf-8')
    documents = loader.load()
    text_splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
    texts = text_splitter.split_documents(documents)

    embeddings = CustomEmbeddings()
    db = lancedb.connect('./web/documents/lancedb_storage')
    vector_db = LanceDB.from_documents(
        documents=texts, embedding=embeddings,
        connection=db, table_name='my_knowledge_base',
        mode='overwrite',   # 覆盖已有数据
    )
```

**逐行讲解**：

- `TextLoader` —— LangChain 的文档加载器，读取文本文件
- `data.txt` —— 知识库的原始文档（如"阿里云百炼使用指南"），`.gitignore` 排除了不提交
- `RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)` —— 把长文档切成每段 500 字的片段，相邻片段重叠 50 字。**为什么要有重叠**：防止一句话刚好被切在两段的边界导致语义断裂
- `LanceDB.from_documents(...)` —— 一键完成"向量化 + 存库"。LangChain 自动遍历所有片段 → 调用 `embed_documents` → 把向量和文字存入 LanceDB 表
- `mode='overwrite'` —— 覆盖模式。每次运行重新创建整张表，旧数据清空
