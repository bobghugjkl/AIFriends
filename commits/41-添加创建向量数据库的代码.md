## 二、使用了什么技术

| 技术/工具 | 用途 |
|-----------|------|
| LangChain `TextLoader` | 加载文本文件作为文档 |
| LangChain `RecursiveCharacterTextSplitter` | 将文档切分为指定大小的片段（chunk_size=500, chunk_overlap=50）（为什么要切文档？两个原因：一是AI每次能处理的文字量有限（上下文窗口），一整本书塞不进去；二是向量搜索时，如果整本书是一个向量，搜"第三章的内容"很难精确匹配。切成500字左右的小块后，每块独立向量化，搜索时能精确命中相关段落。`chunk_overlap=50`意思是相邻两块之间重叠50个字——防止刚好在段落边界切开导致信息断裂，重叠区保证边界附近的上下文不丢失） |
| LangChain `Embeddings` 基类 | 自定义向量化类的抽象基类 |
| OpenAI 客户端 | 调用 DeepSeek 的 Embedding API（text-embedding-v4, 1024维） |
| LanceDB `from_documents()` | 一键完成向量化并存入 LanceDB（mode='overwrite'） |

---

## 三、整体架构 / 数据流

```
Document Ingestion Pipeline:

data.txt
   │
   ▼
TextLoader（读取原始文档）
   │
   ▼
RecursiveCharacterTextSplitter（chunk_size=500, chunk_overlap=50）
   │  将长文档切割为多个文本片段，相邻片段重叠50字符
   ▼
CustomEmbeddings.embed_documents（批量向量化）
   │  每批最多10条，调用 DeepSeek API → text-embedding-v4 → 1024维向量
   ▼
LanceDB.from_documents（documents + embeddings + connection）
   │  mode='overwrite' → 覆盖已有数据
   ▼
lancedb_storage/ 目录 ← 向量数据库持久化存储
```

## 四、新增文件：`custom_embeddings.py` —— 自定义 Embedding 类

**路径**：`backend/web/documents/utils/custom_embeddings.py`

**完整源码（31 行）：**

```python
import os

from langchain_core.embeddings import Embeddings
from openai import OpenAI


class CustomEmbeddings(Embeddings):
    def __init__(self):
        self.client = OpenAI(
            api_key=os.getenv("API_KEY"),
            base_url=os.getenv("API_BASE")
        )

    def embed_documents(self, texts):
        batch_size = 10
        all_embeddings = []
        for i in range(0, len(texts), batch_size):
            batch = texts[i: i + batch_size]
            batch = [t for t in batch if t.strip()]
            if not batch:
                continue
            response = self.client.embeddings.create(
                model="text-embedding-v4",
                input=batch,
                dimensions=1024
            )
            all_embeddings.extend([data.embedding for data in response.data])
        return all_embeddings

    def embed_query(self, text):
        return self.embed_documents([text])[0]
```

**逐行讲解：**

- `Embeddings` —— LangChain 的抽象基类。继承它并实现两个方法：`embed_documents`（批量向量化）和 `embed_query`（单条查询向量化）
- `__init__` —— 初始化 OpenAI 客户端。`api_key` 和 `base_url` 从环境变量读取（`.env` 文件中配置）
- `embed_documents` —— 批量向量化方法：
  - `batch_size = 10` —— API 一次最多处理 10 条，分批防止超出限额
  - `batch = [t for t in batch if t.strip()]` —— 过滤空字符串（空字符串向量化无意义）
  - `model="text-embedding-v4"` —— DeepSeek 的文本向量化模型
  - `dimensions=1024` —— 每个文本被转成 1024 个浮点数（1024 维向量）。维度越高语义表示越精细，但计算和存储成本越高
  - `response.data` —— API 返回的数据列表，每个元素包含一个 `embedding` 属性
  - `[data.embedding for data in response.data]` —— 提取所有向量
- `embed_query` —— 单条查询向量化，直接调用 `embed_documents([text])[0]`

## 五、新增文件：`insert_documents.py` —— 灌库脚本

**路径**：`backend/web/documents/utils/insert_documents.py`

**完整源码（26 行）：**

```python
import lancedb
from langchain_community.document_loaders import TextLoader
from langchain_community.vectorstores import LanceDB
from langchain_text_splitters import RecursiveCharacterTextSplitter

from web.documents.utils.custom_embeddings import CustomEmbeddings


def insert_documents():
    loader = TextLoader('./web/documents/data.txt', encoding='utf-8')
    documents = loader.load()
    text_splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
    texts = text_splitter.split_documents(documents)
    print(f"已切分成 {len(texts)} 个片段。")

    embeddings = CustomEmbeddings()
    db = lancedb.connect('./web/documents/lancedb_storage')
    vector_db = LanceDB.from_documents(
        documents=texts,
        embedding=embeddings,
        connection=db,
        table_name='my_knowledge_base',
        mode='overwrite',
    )
    print(f"已插入 {vector_db._table.count_rows()} 行数据。")
```

**逐行讲解：**

- `TextLoader('./web/documents/data.txt', encoding='utf-8')` —— LangChain 的文档加载器，读取文本文件。`encoding='utf-8'` 确保中文正确读取
- `documents = loader.load()` —— 加载文档。返回一个包含 `Document` 对象的列表。`Document` 有 `page_content`（文本内容）和 `metadata`（元数据）
- `RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)` —— 把长文档切成每段 500 字的片段，相邻片段重叠 50 字。**为什么要有重叠**：防止一句话刚好被切在两段的边界导致语义断裂。默认的分隔符优先级：`\n\n` > `\n` > `。` > 空格 > 字符
- `texts = text_splitter.split_documents(documents)` —— 执行切分。返回切分后的 `Document` 列表，每个包含文本内容和元数据（如源文件名）
- `CustomEmbeddings()` —— 创建自定义 Embedding 实例
- `lancedb.connect('./web/documents/lancedb_storage')` —— 连接（或创建）LanceDB 数据库。如果 `lancedb_storage/` 目录不存在会自动创建
- `LanceDB.from_documents(...)` —— 一键完成"向量化 + 存库"。LangChain 自动遍历所有片段 -> 调用 `embed_documents` -> 把向量和文字存入 LanceDB 表
  - `documents=texts` —— 切分后的文档片段列表
  - `embedding=embeddings` —— 自定义的 Embedding 实例
  - `connection=db` —— LanceDB 数据库连接
  - `table_name='my_knowledge_base'` —— 表名
  - `mode='overwrite'` —— 覆盖模式。每次运行重新创建整张表，旧数据清空
