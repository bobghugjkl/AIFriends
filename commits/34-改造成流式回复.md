## 一、这次提交做了什么

把上一版"等 AI 全部说完才返回"改成了**流式输出（SSE）**——AI 生成一个字就推送一个字到前端，像 ChatGPT 一样逐字出现。（什么是SSE？Server-Sent Events，服务器推送事件。普通HTTP请求像打电话——你拨号，对方接听后说一段话，说完挂断。SSE像收音机广播——你打开收音机（建立连接），电台持续不断地推送内容，你不会挂断。在技术层面，SSE是HTTP的一个"长连接"模式：客户端发一个请求，服务器不立即关闭连接，而是一直保持打开状态，每当有新内容就写一段数据过去，格式是`data: 内容\n\n`。客户端通过`EventSource`API监听，每收到一个`data:`行就触发一次回调。好处是：AI回复的第一个字不用等全部生成完就能给用户看到，体验从"等5秒后看到完整回复"变成"立刻看到逐字蹦出来"。ChatGPT那种逐字效果就是用的SSE或类似机制）

---

## 二、使用了什么技术

| 技术 | 用途 |
|------|------|
| SSE（Server-Sent Events） | HTTP 长连接流式推送，格式 `data: <JSON>\n\n` |
| Django `StreamingHttpResponse` | 接收 Python 生成器，边生成边发送 |
| Python `yield` 生成器 | 每 yield 一次推送一块数据 |
| LangGraph `app.stream()` | 流式调用 LLM，返回 token 迭代器 |
| `@microsoft/fetch-event-source` | 浏览器 SSE 客户端，支持 POST |

---

## 三、整体架构

```
浏览器 ←── SSE 流 ←── Django StreamingHttpResponse ←── LangGraph app.stream() ←── DeepSeek API
                                                    (生成器 yield token by token)
```

**核心改动——event_stream() 生成器 + StreamingHttpResponse：**

改之前（同步 invoke，控制台打印结果）：
```python
        res = app.invoke(inputs)
        print(res['messages'][-1].content)
        return Response({'result': 'success'})
```

改之后（流式 stream，SSE 推送）：
```python
        def event_stream():
            full_usage = {}
            for msg, metadata in app.stream(inputs, stream_mode="messages"):
                if isinstance(msg, BaseMessageChunk):
                    if msg.content:
                        yield f'data: {json.dumps({"content": msg.content}, ensure_ascii=False)}\n\n'
                    if hasattr(msg, 'usage_metadata') and msg.usage_metadata:
                        full_usage = msg.usage_metadata
            yield 'data: [DONE]\n\n'
            print(full_usage)

        response = StreamingHttpResponse(event_stream(), content_type='text/event-stream')
        response['Cache-Control'] = 'no-cache'
        return response
```

**逐行讲解：**

- `def event_stream():` —— 生成器函数。用 `yield` 不用 `return`，每次 yield 推一块数据到客户端。（什么是生成器/generator？普通的`return`像一次性送出一整箱货——函数执行完把所有结果打包返回。`yield`像一个传送带——函数每次"产出"一点东西，暂停，等外面拿走后再继续"产出"下一点。打个比方：`return`是快递员把整个包裹放你家门口就走了；`yield`是流水线工人站传送带旁，出来一个零件递给下游一个，再等下一个。为什么聊天要用yield？因为AI生成回复是一点一点出来的——"今天"→"天气"→"真好"，如果用return，你必须等三个词都生成完才能一次性拿到；用yield，每生成一个词就立刻推送给前端，用户看到逐字显示。Django的`StreamingHttpResponse`正是为生成器设计的——它接收一个生成器，边迭代边写HTTP响应，不用在内存里攒完整回复）
- `app.stream(inputs, stream_mode="messages")` —— 流式调用 LLM（不是 `invoke`）。返回迭代器，每迭代一次拿到一个消息块。（什么是流式调用？普通调用`invoke()`是把问题发给AI，等AI完整回答后才返回结果——像发短信等回复。流式调用`stream()`是边生成边返回——像打电话，对方说一个词你听一个词。在技术层面，AI大模型生成文字是一块一块（token/chunk）生成的——它先生成第一个"字"，然后根据第一个字生成第二个字，以此类推。流式模式让服务器不用等所有字都生成完，每生成一小块就立刻发出去。`stream_mode="messages"`指定每次回调的消息类型模式而不是原始token模式）
- `for msg, metadata in app.stream(...)` —— 遍历。AI 每生成一点文字就触发一次循环体
- `isinstance(msg, BaseMessageChunk)` —— 过滤非文本块
- `if msg.content:` —— 有文字内容才推送
- `yield f'data: {json.dumps({"content": msg.content}, ensure_ascii=False)}\n\n'` —— SSE 格式：`data: <json>\n\n`。双换行表示一个事件结束。`ensure_ascii=False` 让中文正常显示
- `hasattr(msg, 'usage_metadata')` —— 最后一条消息附带 token 统计
- `yield 'data: [DONE]\n\n'` —— 结束信号。前端收到 `[DONE]` 后知道流结束
- `print(full_usage)` —— 调试代码（后续提交改为存数据库）
- `StreamingHttpResponse(event_stream(), content_type='text/event-stream')` —— Django 边迭代生成器边写 HTTP 响应体
- `response['Cache-Control'] = 'no-cache'` —— 禁止浏览器缓存流式内容

### 4.3 `streamApi.js`——前端 SSE 客户端（新文件, 84行）

```javascript
import { fetchEventSource } from '@microsoft/fetch-event-source';
import { useUserStore } from "@/stores/user.js";
import api from "./api.js";

const BASE_URL = 'http://127.0.0.1:8000'

export default async function streamApi(url, options = {}) {
    const userStore = useUserStore();

    const startFetch = async () => {
        return await fetchEventSource(BASE_URL + url, {
            method: options.method || 'POST',
            headers: {
                'Content-Type': 'application/json',
                'Authorization': `Bearer ${userStore.accessToken}`,
                ...options.headers,
            },
            body: JSON.stringify(options.body || {}),

            openWhenHidden: true,
            async onopen(response) {
                if (response.status === 401) {
                    try {
                        await api.post('/api/user/account/refresh_token/', {});
                        throw new Error("TOKEN_REFRESHED");
                    } catch (err) {
                        throw err;
                    }
                }

                if (!response.ok || !response.headers.get('content-type')?.includes('text/event-stream')) {
                    const errorData = await response.json().catch(() => ({}));
                    throw new Error(errorData.detail || `请求失败: ${response.status}`);
                }
            },

            onmessage(msg) {
                if (msg.data === '[DONE]') {
                    if (options.onmessage) options.onmessage('', true);
                    return
                }
                try {
                    const json = JSON.parse(msg.data);
                    if (options.onmessage) options.onmessage(json, false);
                } catch (e) {
                    console.error("流解析失败:", e);
                }
            },

            onerror(err) {
                if (err.message === "TOKEN_REFRESHED") {
                    return startFetch();
                }
                if (options.onerror) {
                    options.onerror(err);
                }
                throw err;
            },

            onclose: options.onclose,
        });
    };

    return await startFetch();
}
```

**逐段讲解：**

- `import { fetchEventSource } from '@microsoft/fetch-event-source'` —— 浏览器原生 `EventSource` 只支持 GET，微软这个库支持 POST + 自定义 headers
- `const startFetch = async () => {...}` —— 把请求包成函数，方便 Token 刷新后递归重试
- `fetchEventSource(BASE_URL + url, {...})` —— 发起 SSE 连接
- `headers: { 'Authorization': \`Bearer ${userStore.accessToken}\` }` —— 手动加 JWT 头（不走 Axios 拦截器）
- `body: JSON.stringify(options.body || {})` —— JSON 请求体
- `openWhenHidden: true` —— 后台标签页也能接收 SSE

**`onopen(response)`**：
- `if (response.status === 401)` —— Token 过期 → 调 Axios 刷新 → 抛 `"TOKEN_REFRESHED"` → 在 `onerror` 中重试
- `!response.headers.get('content-type')?.includes('text/event-stream')` —— 如果不是 SSE（可能是代理错误页），报错

**`onmessage(msg)`**：
- `if (msg.data === '[DONE]')` —— 流结束，`options.onmessage('', true)`（第二个参数=true）
- `JSON.parse(msg.data)` —— 解析 → `options.onmessage(json, false)`

**`onerror(err)`**：
- `if (err.message === "TOKEN_REFRESHED")` —— 递归重试 `startFetch()`
- `throw err` —— 阻止默认重试行为

**`return await startFetch()`** —— 执行

### 4.5 `InputField.vue`——对接流式 API

```diff
+import {ref, useTemplateRef} from "vue";
+import streamApi from "@/js/http/streamApi.js";
+
+const props = defineProps(['friendId'])
+const inputRef = useTemplateRef('input-ref')
+const message = ref('')
+let isProcessing = false
+
+function focus() {
+  inputRef.value.focus()
+}
+
+async function handleSend() {
+  if (isProcessing) return
+  isProcessing = true
+  const content = message.value.trim()
+  if (!content) return
+  message.value = ''
+
+  try {
+    await streamApi('/api/friend/message/chat/', {
+      body: {
+        friend_id: props.friendId,
+        message: content,
+      },
+      onmessage(data, isDone) {
+        if (isDone) {
+          isProcessing = false
+        } else if (data.content) {
+          console.log(data.content)
+        }
+      },
+      onerror(err) {
+        isProcessing = false
+      },
+    })
+  } catch (err) {
+    console.log(err)
+    isProcessing = false
+  }
+}
+
+defineExpose({
+  focus,
+})
```

**逐行讲解：**

- `defineProps(['friendId'])` —— 接收父组件传的好友 ID
- `ref('')` —— 输入框文字绑定。之前没有 v-model，输入了字也拿不到
- `isProcessing = false` —— 防止重复发送。流接收期间不允许再发
- `focus()` —— 暴露给父组件的自动聚焦方法
- `handleSend()` —— 发消息：防重复 → 取值 → 清空输入框 → `streamApi('/api/friend/message/chat/', ...)` → onmessage 中打印 token（后续改为渲染到界面）
- `defineExpose({focus})` —— 暴露给父组件

**Template 改动：**

```diff

+  <form @submit.prevent="handleSend" class="absolute bottom-4 ...">
     <input
+        ref="input-ref"
+        v-model="message"
         ...
     >
-    <div class="absolute right-2 ...">
+    <div @click="handleSend" class="absolute right-2 ...">
```

- `<form @submit.prevent="handleSend">` —— 改为表单，按 Enter 也能发送
