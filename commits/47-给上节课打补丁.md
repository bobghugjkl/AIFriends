## 一、关闭对话框时不关闭 Modal

**文件**：`ChatField.vue`

```diff
 function handleClose() {
-  modalRef.value.close()
   inputRef.value.close()     // 只关闭输入流，不关Modal
 }
```

`handleClose` 只在 `@close` 事件触发时调用（用户点 X 或按 ESC 关闭对话框）。之前手动调了 `modalRef.close()` 会形成**循环调用**——`handleClose` → `modalRef.close()` → 触发 `@close` → 又调 `handleClose`。修复后 `handleClose` 只负责清理（关闭音频流），不负责关 Modal。
